# 目的地 / 准备事项 / 记录编辑 · 接口文档

> 配套需求：`docs/渡清川_目的地与准备事项_需求文档.html`  
> 前缀：`/api/v1` · 鉴权：`Authorization: Bearer <token>`  
> 成功响应为**裸 JSON**（不包 `{data}`）；错误为 `{ code, message, timestamp, path }`

---

## 1. 目的地 `destinations`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/journeys/:journeyId/destinations` | 列表，按 `sortOrder` 升序（不含软删） |
| `POST` | `/journeys/:journeyId/destinations` | 新增 |
| `PATCH` | `/destinations/:destinationId` | 部分更新 |
| `DELETE` | `/destinations/:destinationId` | 软删除 → **204** |
| `PATCH` | `/journeys/:journeyId/destinations/reorder` | `{ items:[{id,sortOrder}] }` → **204** |

**创建 / 更新字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 必填 1–30 |
| `latitude` / `longitude` | number? | 同时有或同时空 |
| `address` | string? | ≤100 |
| `category` | enum | `SIGHT` / `FOOD` / `STAY` / `SHOPPING` / `OTHER`，默认 `OTHER` |
| `note` | string? | ≤120 |
| `images` | string[] | COS URL，最多 9 |
| `isMust` | boolean | 默认 false |
| `dayIndex` | int? | null=未安排 |

同旅程下 `name` 不可重复（软删除外）→ `409` / `40901`。

**列表项示例**

```json
{
  "id": "uuid",
  "journeyId": "uuid",
  "name": "清水寺",
  "latitude": 34.9948,
  "longitude": 135.785,
  "address": "京都府京都市东山区",
  "category": "SIGHT",
  "note": "清晨人少",
  "images": ["https://..."],
  "isMust": true,
  "dayIndex": 1,
  "sortOrder": 0,
  "createdAt": "...",
  "updatedAt": "..."
}
```

## 2. 准备事项 `checklist`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/journeys/:journeyId/checklist` | 列表；无数据时自动写入默认 4 项 |
| `POST` | `/journeys/:journeyId/checklist` | 新增 |
| `PATCH` | `/checklist/:itemId` | 更新 title / isDefaultChecked / remindBeforeDays / sortOrder |
| `PATCH` | `/checklist/:itemId/toggle` | `{ isChecked: boolean }` |
| `DELETE` | `/checklist/:itemId` | 软删除 → **204** |
| `PATCH` | `/journeys/:journeyId/checklist/reorder` | `{ items:[{id,sortOrder}] }` → **204** |

**创建字段**：`title`（1–30）、`isDefaultChecked?`、`remindBeforeDays?`（1–365 或 null）  
新建时若 `isDefaultChecked=true`，则 `isChecked` 同步为 true。

旅程卡片 `planProgress` / `confirmedCount` **优先读本表**（无数据时回退旧 `journey_plans.checks` JSON）。

## 3. 记录编辑 `records`（entries 别名）

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/journeys/:id/records?dayIndex=1` | 按天筛选，按 `recordedAt` 升序；不传 dayIndex 返回全部 |
| `GET` | `/journeys/:id/entries` | 原时间线列表（仍可用） |
| `PATCH` | `/records/:recordId` | 部分更新 |
| `PATCH` | `/records/:recordId/time` | `{ recordedAt, dayIndex? }` |
| `DELETE` | `/records/:recordId` | 物理删除 → `{ deleted:true, id }` |
| `DELETE` | `/journeys/:id/entries/:entryId` | 原删除路径（仍可用） |

**PATCH body（均可选）**

```json
{
  "recordedAt": "2025-10-18T07:24:00.000Z",
  "dayIndex": 1,
  "content": "更新后的文字",
  "images": ["https://..."],
  "audioUrl": "https://...",
  "audioDuration": 12,
  "locationTag": { "name": "清水寺", "lat": 34.99, "lng": 135.78 },
  "expense": { "category": "food", "amount": 180, "note": "亲子丼" }
}
```

- `images` / `audioUrl` / `locationTag` / `expense` 传 `null` 或空数组表示清除（`images: []`、`audioUrl: null` 等）
- `expense.amount`：优先按**元**转分；也可传 `amountCent`
- `recordedAt` 须在旅程日期 ±1 天内
- 文字 / 图片 / 语音至少一项非空，否则 `40004`

读出额外字段：`recordedAt`、`images[]`、`audioUrl`、`audioDuration`、`locationTag`（原 `location` / `media` / `voice` 仍保留兼容）。

---

## 4. 错误码（本模块）

| code | HTTP | 场景 |
|------|------|------|
| `40001` | 400 | 名称/标题非法、时间越界等 |
| `40002` | 400 | 坐标不成对 |
| `40003` | 400 | 图片超过 9 张 |
| `40004` | 400 | 记录无文字/图/语音 |
| `40901` | 409 | 同名目的地/事项 |
| `40401` | 404 | 资源不存在或已删 |

---

## 5. 与旧 `/plan` 的关系

- `GET/PUT/PATCH /journeys/:id/plan` **保留**（JSON `places`/`checks`），旧客户端可继续用。
- 新前端请走 `/destinations`、`/checklist`。
- 列表卡片：`placeCount` 优先 destinations；`planProgress` 优先 checklist。
