## 1. 游记四态（Handbook）

### 阶段枚举

| phase | 条件 | 前端主行动 |
|-------|------|------------|
| `need_more` | `recordCount < 3` | 继续补充 |
| `ready` | `recordCount ≥ 3` 且无 Guide | 一键生成 |
| `generated` | 有 Guide，尚无分享票/分享事件 | 预览 / 分享 |
| `shared` | 有 `shares` 票据或非 view 的 `share-events` | 查看分享 |

阈值常量：`minRecords = 3`（与前端 `HANDBOOK_MIN_RECORDS` 一致）。

### 1.1 专用工作台列表（推荐）

```http
POST /journeys/handbook/list
{ "phase"? : "need_more"|"ready"|"generated"|"shared" }
```

```json
{
  "minRecords": 3,
  "total": 2,
  "list": [
    {
      "journey": { "id", "title", "status", "displayStatus", "..." },
      "journeyStats": { "recordCount", "placeCount", "expenseTotalCent" },
      "planProgress": { "checkDone", "checkTotal", "pct", "source": "checklist" },
      "handbook": {
        "phase": "ready",
        "recordCount": 4,
        "minRecords": 3,
        "hasGuide": false,
        "guideId": null,
        "templateId": null,
        "shareSummary": {
          "ticketCount": 0,
          "eventCount": 0,
          "viewCount": 0,
          "latestToken": null
        }
      }
    }
  ]
}
```

### 1.2 旅程 list / get / detail 已带 `handbook`

`POST /journeys/list|get|detail` 模块化响应新增同构 `handbook` 模块；平铺字段另有 `handbookPhase`、`hasGuide`（兼容）。

**前端可删除**：工作台对每条旅程再拉 `guideApi.get` + `shareApi.getStats` 的拼装逻辑。

## 2. Guide 生成契约（游记产出）

```http
POST /journeys/guide/create
{
  "journeyId": "...",
  "templateId": "basic" | "T1" | "T2" | "T3" | "T4" | "T5" | "T6",
  "template": "兼容旧字段，优先 templateId",
  "force": false
}
```

| 规则 | 说明 |
|------|------|
| 门槛 | **至少 3 条记录**，且至少一张图或一个定位 |
| 幂等 | 已有 Guide 且 `force≠true` → `idempotent:true` 直接返回 |
| force | `true` 强制重生成并覆盖 payload |
| 同步 | 仍为同步落库；无异步 job（海报出图另管线） |

响应新增：`templateId`、`productName: "游记"`。

**与模版中心关系：**

| 管线 | 职责 |
|------|------|
| Guide `templateId` | 服务端拼装游记 payload（亮点/花费/城市） |
| 模版中心 T1–T6 海报 | **客户端 Canvas** 按模版渲染 → 上传 media → 登记 URL |

## 3. 海报出图 + 小程序码

### 3.1 登记海报（客户端渲染）

```http
POST /shares/poster/export
{
  "journeyId": "...",
  "templateId": "T1",
  "imageUrl": "https://... 或 /api/v1/files/...",
  "shareToken"? : "可选，关联已有票据"
}
```

```json
{
  "ok": true,
  "mode": "client_render",
  "templateId": "T1",
  "imageUrl": "...",
  "exportPolicy": { "watermark": true, "maxResolution": 720 }
}
```

流程建议：`media/prepare → local-upload → confirm` → 本接口登记 → 分享通道用 `imageUrl`。

### 3.2 小程序码

```http
POST /shares/wxacode
{ "journeyId"? , "shareToken"? , "page"? : "pages/ShareView/ShareView" }
```

- `journeyId` / `shareToken` 至少一个  
- 已配 `WX_APPID/SECRET`：调 `getwxacodeunlimit`，落盘返回 `imageUrl`  
- 未配置：`mock:true` 占位图（联调用）

本地图仍需 `AuthImage` / Bearer 访问。

## 4. P1 语义纠偏

### 4.1 `/me` 与 profile

`GET /me` 现与资料对齐，含：

- `gender` / `birthday` / `identities[]` / `bio` / …
- `stats.footprintCities` / `stats.tripCount`

资料编辑仍推荐 `PATCH /user/profile`（字段更全）；`/me` 刷新不再丢 identities。

### 4.2 足迹城市

`POST /stats/overview` 增加 **`footprintCities`**（= `totalPlaces`，口径：自由打卡 `location.name` 去重，**不是** `journey.destination` 字符串去重）。

### 4.3 checklist 真源

- `planProgress.source === "checklist"`
- `plan.checks` 响应带 `checksDeprecated: true`
- `POST /journeys/plan/toggleCheck` **废弃**（仅旧客户端兼容）；进度请用 `/checklist/toggle`

### 4.4 已完成旅程补记

后端 **允许** finished 旅程继续 sync/记一笔。若产品要禁止，前后端需再统一拦截。
