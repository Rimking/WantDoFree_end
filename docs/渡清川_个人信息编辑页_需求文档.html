1概述

本页面用于用户维护个人资料与旅行偏好，是「我的」模块的二级页。本文档定义页面结构、字段、状态、校验，以及前端需要的接口与后端落地所需的模型与 API。

1.1 页面入口

  • 路径：pages/mine/profile-edit（uni-app 路由）
  • 来源：「我的」页 个人资料 行 → 跳转本页；亦可从头像区点击进入。
  • 导航栏：左「取消」、中「编辑资料」、右「保存」（保存按钮与底部主按钮二选一，推荐仅保留底部吸底主按钮，导航栏右按钮置灰或隐藏，避免双提交）。

1.2 用户故事

  • 作为注册用户，我希望修改昵称、头像、性别、生日、所在地、旅行身份、常用出发地与个性签名，让我的主页更个性化。
  • 作为用户，我希望修改即时生效并看到成功反馈，且不符合规则时能就地提示，而不是提交后才报错。
  • 作为用户，我不希望手机号被随意修改（已绑定微信/手机，属账号安全项，仅展示脱敏）。

1.3 非目标（本期不做）

  • 不改绑手机号、不解绑微信、不做账号注销（独立安全流程）。
  • 不做会员升级付费（会员仅展示）。
  • 旅行身份字典的运营后台配置（本期字典写死在接口返回，不提供管理端）。

3页面交互状态

与设计稿 5 屏一一对应，前端按状态机实现；保存中态为设计稿隐含态（保存按钮 loading），文档补全。

状态 1 · 默认编辑态
编辑主页
拉取资料回显；头像 + 分组卡片（基础信息 / 旅行偏好 / 账号）；底部吸底「保存修改」按钮。
状态 2 · 头像更换
Action Sheet
底部半屏：拍照 / 从相册选择 / 查看大图 / 取消。选图后前端裁方形 → 调预签名接口 → 直传 COS → 回显。
状态 3 · 单项选择
底部选择器
性别（3 选 1，含选中勾）、生日（日期滚轮）；确认后回填对应行。
状态 4 · 校验 + 多选
昵称错误 / 身份多选
昵称 <2 字符：行红底 + 行内「至少 2 个字符」；旅行身份 chip 多选，超过 3 个禁止再加（或自动替换最早选）。
状态 5 · 保存中
提交 loading（隐含）
点「保存修改」→ 按钮转圈 + 禁用；校验通过才发请求；失败保持编辑态并 toast 错误。
状态 6 · 成功
保存成功 Toast
墨青半透明卡片 + 青色对勾「资料已保存」，1.5s 后自动返回上一页（「我的」）。

4校验规则

前端做即时校验（就地提示），后端做权威校验（返回错误码）。两侧规则必须一致。

字段前端即时校验后端校验
昵称失焦即校验；<2 或 >12 字符行内报错；禁止首尾空格长度 2–12；敏感词过滤；唯一性可选（见 7.5）
性别枚举三选一枚举值校验
生日日期 ≤ 今天日期格式 + 范围 1900-01-01 ~ 今天
所在地必须选到「市」级才允许保存cityCode 必须存在于行政区划表
旅行身份选中数 ≤ 3；超限拦截每项 code 必须存在于字典；数组长度 ≤ 3
常用出发地≤64 字符≤64 字符
个性签名实时字数 12/40，超限禁输≤40 字符
头像格式/大小前端拦截content-type 白名单；文件大小 ≤2MB（COS 策略）
保存按钮在「存在未通过校验项」或「内容相对服务端无变更」时应置灰，避免无效请求。变更检测：进入页面时快照原始资料，diff 决定是否可保存。

5前端实现要点

5.1 组件与样式

  • 延续「精修版」设计系统：纸感背景 #FBF8F4、卡片顶部内高光 inset 0 1px 0 rgba(255,255,255,.7)、发丝描边 rgba(31,42,46,.07)、品牌阴影与珊瑚光晕。
  • 图标统一 24px 线性圆角 SVG（ic-*.svg 资源库），无 emoji。
  • 头像：青→蓝→珊瑚渐变圆 + 白色相机 badge；点击触发状态 2。
  • 底部吸底保存按钮：珊瑚渐变 + 投影光晕，env(safe-area-inset-bottom) 适配。

5.2 动效

  • Action Sheet / 底部选择器：从下往上 translateY + 遮罩淡入（250ms），缓动 cubic-bezier(0.16,1,0.3,1)。
  • 身份 chip 选中：珊瑚底 + 0.15s 过渡。
  • 成功 Toast：scale 0.9→1 + 淡入，1.5s 自动消失。
  • 必须支持 prefers-reduced-motion：用户开启「减少动态效果」时关闭位移动效，仅保留淡入。

5.3 无障碍

  • 可点击行最小高度 54px（≥44px 触控目标）；
  • 输入框有 label 关联与 placeholder；错误用 aria-live 播报；
  • 头像更换 sheet 对焦管理：打开时焦点移入首个选项，关闭回焦头像。

6数据模型（Prisma / PostgreSQL）

在现有 User 模型上扩展字段；旅行身份用「字典表 + 关联表」实现，便于接口返回选项与扩展。

// prisma/schema.prisma（增量部分）
enum Gender {
  MALE
  FEMALE
  UNKNOWN
}

enum MemberLevel {
  FREE
  PRO
}

model User {
  id             String          @id @default(cuid())
  openid         String          @unique
  unionid        String?         @unique
  nickname       String?         @db.VarChar(12)
  avatarUrl      String?
  gender         Gender          @default(UNKNOWN)
  birthday       DateTime?
  provinceCode   String?         @db.Char(6)
  cityCode       String?         @db.Char(6)
  departureCity  String?         @db.VarChar(64)
  bio            String?         @db.VarChar(40)
  phone          String?         @db.VarChar(20)   // 加密存储
  memberLevel    MemberLevel     @default(FREE)
  identities     UserIdentity[]
  createdAt      DateTime        @default(now())
  updatedAt      DateTime        @updatedAt
}

model TravelIdentityDict {
  code   String         @id
  name   String
  sort   Int            @default(0)
  users  UserIdentity[]
}

model UserIdentity {
  userId       String
  identityCode String
  user         User              @relation(fields: [userId], references: [id], onDelete: Cascade)
  identity     TravelIdentityDict @relation(fields: [identityCode], references: [code], onDelete: Cascade)
  @@id([userId, identityCode])
}
迁移注意：现有 User 若无这些字段需 prisma migrate dev 增量迁移；phone 若已明文存储，迁移时应做一次性加密回填（建议应用层迁移脚本）。provinceCode/cityCode 参考国家标准行政区划代码（6 位）。

7接口定义

Base URL：/api/v1/user。鉴权：除明确说明外均需 Authorization: Bearer <token>（小程序登录拿到的用户 token）。统一响应包：{ code, message, data }，code=0 成功。

GET/profile

获取当前用户资料（进入页面首屏调用）。

响应 200:
{
  "code": 0,
  "data": {
    "userId": "usr_2x9a",
    "nickname": "旅人",
    "avatarUrl": "https://cdn.dqc.com/avatars/usr_2x9a_a1b2.webp",
    "gender": "FEMALE",
    "birthday": "1995-08-12",
    "provinceCode": "330000",
    "cityCode": "330100",
    "region": "浙江·杭州",          // 后端按编码拼接展示串
    "departureCity": "杭州萧山",
    "bio": "把每一次出发，都藏进清川。",
    "phoneMasked": "138****6621",
    "memberLevel": "FREE",
    "identities": ["backpacker", "foodie"],
    "stats": { "footprintCities": 12, "tripCount": 8 }
  }
}
region 由后端用 provinceCode+cityCode 查表拼接，前端无需本地拼；phoneMasked 由后端脱敏，前端不持有明文。
PATCH/profile

局部更新资料（点「保存修改」调用）。仅传变更字段，后端合并更新。

请求 body（全部可选，按需传）:
{
  "nickname": "旅人",
  "avatarUrl": "https://cdn.dqc.com/avatars/usr_2x9a_a1b2.webp",
  "gender": "FEMALE",
  "birthday": "1995-08-12",
  "provinceCode": "330000",
  "cityCode": "330100",
  "departureCity": "杭州萧山",
  "bio": "把每一次出发，都藏进清川。",
  "identities": ["backpacker", "foodie"]
}

响应 200:
{ "code": 0, "data": { "updatedAt": "2026-07-23T13:20:00Z" } }
// 建议同时返回最新 profile 全量，便于前端直接回显、省一次 GET
后端必须对每个传入字段按第 4 节规则校验；任意字段不合法返回对应错误码（见第 8 节），整条请求不生效（原子更新）。
POST/avatar/presign

获取头像直传 COS 的临时凭证与最终 CDN 地址。推荐「服务端 STS 临时密钥 + 前端 cos-wx-sdk 直传」，避免前端长期持秘钥。

请求 body:
{ "ext": "jpg", "contentType": "image/jpeg" }

响应 200:
{
  "code": 0,
  "data": {
    "secretId": "AKID_temp_xxx",
    "secretKey": "temp_xxx",
    "sessionToken": "xxx",
    "expiredTime": 1690000300,
    "bucket": "dqc-avatar-1250000000",
    "region": "ap-guangzhou",
    "key": "avatars/usr_2x9a_1690000000.jpg",
    "cdnUrl": "https://cdn.dqc.com/avatars/usr_2x9a_1690000000.jpg",
    "expiresIn": 300
  }
}
前端流程：① 调 /avatar/presign 拿凭证；② cos.postObject / cos.uploadFile 直传（带 sessionToken）；③ 成功后把 cdnUrl 作为 avatarUrl 并入 PATCH 请求。COS 桶策略限制：content-type 白名单、单文件 ≤2MB、仅 avatars/ 前缀可写。

返回旅行身份字典（选项清单 + 最大可选数）。前端不硬编码选项，配置驱动。

响应 200:

  "data": {
    "maxSelect": 3,
    "options": [

POST/nickname/check

昵称实时可用性校验（可选，用于即时反馈；保存时后端仍权威校验）。

请求 body: { "nickname": "旅人" }
响应 200:
{ "code": 0, "data": { "available": true } }
// available=false 时 message 说明原因：已存在 / 含敏感词

9安全与权限

  • 越权防护：PATCH 仅允许修改「当前登录用户」自身资料，禁止传 userId 改他人；服务端以 token 解析出的 userId 为准。
  • 手机号：永不进响应明文，仅返回 phoneMasked；库中加密存储。
  • 头像上传：STS 临时密钥有效期 ≤ 5 分钟、仅限 avatars/ 前缀、单文件 ≤2MB、content-type 白名单；不返回长期秘钥给前端。
  • 输入安全：昵称/签名入库前做 XSS 转义与敏感词过滤；枚举/编码类字段做白名单校验。
  • 限流：/profile(PATCH) 与 /nickname/check 按用户维度限流（如 10 次/分钟）。

11验收标准

前端

  • 进入页面 1s 内回显资料；与「我的」页数据一致。
  • 昵称 <2 字符即时红底报错；签名实时字数统计且 ≤40。
  • 旅行身份最多选 3 个，超限拦截；chip 选中态为珊瑚底。
  • 头像更换 sheet 三选项可用；上传后回显新头像；失败有 toast。
  • 保存成功后 1.5s toast 并自动返回；保存中按钮 loading 禁用。
  • 无变更时保存按钮置灰；减少动态效果下无位移动效。

后端

  • GET /profile 返回字段与第 2/7.1 节一致，region 正确拼接、phoneMasked 脱敏。
  • PATCH /profile 按字段原子校验，非法字段返回对应错误码且整条不生效。
  • POST /avatar/presign 返回 5 分钟内有效 STS 凭证 + 正确 cdnUrl。
  • GET /identities 返回 7 个选项 + maxSelect=3。
  • 越权/限流/枚举白名单全部生效；手机号明文不出现于任何响应。
