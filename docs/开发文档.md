## 2. 本地启动

```bash
cd server
cp .env.example .env   # DB 建议 DB_HOST=127.0.0.1
npm install && npm run build && node dist/main.js
# Swagger: http://localhost:3000/api/docs
```

地图真搜：配置 `TENCENT_MAP_KEY` 或 `AMAP_KEY`（可选 `MAP_PROVIDER`）。

## 3. 接口速查（鉴权：Bearer，登录除外）

> **前端联调请以 [前端对接_接口文档.md](./前端对接_接口文档.md) 为准**（含请求/响应示例与枚举）。

### 账号 / 隐私 / 配额
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/auth/wechat-login` | `{ code }` |
| GET/PATCH | `/me` | 资料 |
| GET | `/me/quota` | 照片/语音配额 |
| GET | `/me/export` | PIPL 全量导出 JSON |
| DELETE | `/me/locations` | 清除本人全部位置 |

### R1 旅程
| 方法 | 路径 | 说明 |
|------|------|------|
| POST/GET | `/journeys` | 新建 / 列表（`?status=`，含花费快照） |
| GET/PATCH/DELETE | `/journeys/:id` | 详情含 plan / 改 / 删 |
| POST | `/journeys/:id/status` | `{ target }` 相邻跃迁 |

### R2 记录
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/journeys/:id/entries/sync` | Outbox 幂等落库 |
| GET | `/journeys/:id/entries` | 时间线 |
| DELETE | `/journeys/:id/entries/:entryId` | 删单条 |
| POST | `/journeys/:id/entries/delete` | `{ entryIds }` 或 `{ from, to }` 整段删 |

### R3 地图
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/map/poi?keyword=&lat=&lng=` | POI 搜索（屏22） |
| GET | `/map/reverse-geocode?lat=&lng=` | 逆地理 |

### R4 / R5 / 分享
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/journeys/:id/expense-summary` | 总额 + 分类(+ratio) + 按天 |
| GET | `/journeys/:id/guide/check` | `{ canGenerate, reason, stats }` |
| POST | `/journeys/:id/guide` | 生成；不达标 400 + canGenerate:false |
| GET | `/guides/:id` | 拉攻略 |
| POST | `/guides/:id/favorite` | 收藏 |
| POST | `/share-events` | `{ journeyId, guideId, channel, viewerId? }` |
| PATCH | `/share-events/:id/viewer` | `{ viewerId }` 回流回填 |

### 草稿 / 媒体 / 支付
| 方法 | 路径 | 说明 |
|------|------|------|
| GET/PUT/DELETE | `/drafts` · `/drafts/:id` | 草稿暂存恢复 |
| GET | `/media/upload-url` | mock 上传 URL |
| POST | `/media/confirm` | 回写 + 扣配额 |
| POST | `/orders` | `{ product }` |
| POST | `/pay/dev-complete` | 本地假支付 |

路径均带前缀 `/api/v1`。

### 攻略门槛

- `entries < 2` → 不可生成  
- 无照片且无定位 → 不可生成  
- 前端应先调 `GET .../guide/check` 禁用按钮；生成接口也会强制校验。

### 隐私

- `isPublic=false` 时攻略 payload **不写**精确 lat/lng（仅地名）  
- 导出给本人含完整坐标（数据可携带）
