## 新增：POI 路径（前端契约）

| 方法 | 路径 | Query |
|------|------|-------|
| GET | `/api/v1/pois/nearby` | `lat,lng,radius?,keyword?,page?,pageSize?` |
| GET | `/api/v1/pois/reverse-geocode` | `lat,lng,getPoi?` |
| GET | `/api/v1/pois/search` | `keyword,city?,lat?,lng?,page?,pageSize?` |

**响应**：

```json
{
  "list": [
    {
      "id": "…",
      "name": "西湖断桥",
      "address": "…",
      "latitude": 30.2588,
      "longitude": 120.149,
      "lat": 30.2588,
      "lng": 120.149
    }
  ],
  "total": 3,
  "provider": "mock"
}
```

旧路径 `/map/poi`、`/map/reverse-geocode` **仍可用**。未配置地图 Key 时返回国内景点风格 mock（杭州一带）。
