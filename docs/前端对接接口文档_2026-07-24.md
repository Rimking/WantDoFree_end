## 0. 约定（必读）

### 0.1 HTTP 方法

| 场景 | 方法 |
|------|------|
| 无业务参数的获取 | **GET**（如 `/me`、`/me/quota`、`/user/identities`） |
| **有参数**的获取 / 所有写入 | **POST**，参数放 **JSON body** |
| 本地文件回读 | **GET** `/files/...`（path 定位，需 Bearer） |

> 旧 GET + query、PATCH/PUT/DELETE 仍保留一期兼容；**新代码请一律走本文 POST 契约**。

### 0.2 响应形态

| 类型 | 形态 |
|------|------|
| 多数业务成功 | **裸 JSON**（模块对象或列表） |
| 统计 `/stats/*` | `{ "code": 0, "message": "ok", "data": ..., "range"? }`；dashboard 的 `range` 在 `data` 内 |
| 错误 | `{ "code", "message", "timestamp", "path", ... }`；HTTP 状态码非 2xx |

### 0.3 模块化（禁止平铺大杂烩）

- 聚合 / 新 list / get：根上只有模块 key（`journey`、`plan`、`entries`…）
- 单查返回的模块对象与聚合内**同名字段同构**
- 优先字段：`coverUrl`、`amountCent`、`nickname`；勿再依赖 `cover`/`cdnUrl` 等别名（兼容期可能仍有）

### 0.4 金额与媒体 kind

- 金额单位：**分（cent）**，字段名 `amountCent` / `totalCent` / `budgetAmount`
- 媒体 kind：**`image` | `audio`**（请求兼容 `photo`/`voice`；响应可有 `legacyKind`）

### 0.5 缓存

业务数据（旅程 / 计划 / 记录 / 统计）**以服务端为准**，进页拉取；勿把本地 store 当真源。token、onboarding、outbox 可本地。

### 2.2 `POST /journeys/list` — 列表

**Request**

```json
{
  "status": "ongoing",
  "displayStatus": null,
  "page": 1,
  "pageSize": 20,
  "modular": true
}
```

| 字段 | 说明 |
|------|------|
| status | `planned` \| `ongoing` \| `finished`（可选） |
| displayStatus | `planning` \| `departing` \| `ongoing` \| `finished`（卡片展示态，可选） |
| page / pageSize | 默认 1 / 20，pageSize≤100 |
| modular | 默认 `true`；`false` 返回旧平铺数组项（不推荐） |

**Response**

```json
{
  "list": [
    {
      "journey": { "id": "...", "title": "...", "coverUrl": "...", "status": "ongoing", "displayStatus": "ongoing" },
      "journeyStats": { "placeCount": 4, "recordCount": 12, "expenseTotalCent": 108700, "todayPlaceCount": 0 },
      "planProgress": { "checkDone": 3, "checkTotal": 8, "pct": 38 }
    }
  ],
  "total": 5,
  "page": 1,
  "pageSize": 20
}
```

列表**不含**完整 places / entries / guide。

### 2.4 `POST /stats/dashboard` — 统计首页

**Request**

```json
{
  "rangeType": "year",
  "start": "2026",
  "end": null,
  "journeyId": null
}
```

| rangeType | start / end |
|-----------|-------------|
| `all` | 可不传 |
| `year` | `start`=`"2026"` 或 `"2026-01-01"` |
| `month` | 按后端解析（传合法年月） |
| `custom` | `start`/`end` = `YYYY-MM-DD` |
| journeyId | 可选，部分子模块按旅程过滤 |

**Response**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "range": { "type": "year", "start": "2026-01-01", "end": "2026-12-31" },
    "overview": { },
    "expenses": { },
    "plans": { },
    "journeys": { },
    "content": { },
    "storage": { }
  }
}
```

二级页只刷新某一块时，打对应单查（字段与 `data.xxx` **同构**）：

| 单查 | Body |
|------|------|
| `POST /stats/overview` | 同 range |
| `POST /stats/expenses` | 同 range + 可选 journeyId |
| `POST /stats/plans` | 同 range |
| `POST /stats/journeys` | 同 range + 可选 status |
| `POST /stats/content` | 同 range |
| `GET` 或 `POST /stats/storage` | 无参 |

## 3. 单查 / 写入（POST 契约）

### 3.1 登录与用户

| 方法 | 路径 | Body / 说明 |
|------|------|-------------|
| POST | `/auth/wechat-login` | `{ "code": "..." }` → `{ token, user }` |
| GET | `/me` | 当前用户摘要 |
| POST | `/me/update` | 资料 patch（兼容 `PATCH /me`） |
| GET | `/me/quota` | 配额：`photo` / `voiceSec` 含 used、limit、remaining |
| POST | `/me/budget/get` | `{ "year": 2026 }` |
| POST | `/me/budget/update` | `{ "year", "amountCent" }` |
| POST | `/me/expense/summary` | `{ "year"? }` |
| GET | `/user/profile` | 完整资料 |
| POST | `/user/profile/update` | 资料编辑保存 |
| GET | `/user/identities` | 旅行身份字典 |
| GET | `/user/regions` | 省市区 |
| POST | `/user/nickname/check` | `{ "nickname" }` |

| 方法 | 路径 | Body |

### 3.4 记录（时间线）

| 方法 | 路径 | Body |
|------|------|------|
| POST | `/journeys/entries/list` | `{ "journeyId", "dayIndex"?, "modular"? }` 默认模块化 Entry[] |
| POST | `/journeys/entries/sync` | `{ "journeyId", "entries": [ ... ] }` |
| POST | `/journeys/entries/delete` | `{ "journeyId", "entryIds"? }` 或 `from`/`to` |
| POST | `/records/update` | `{ "recordId", ...PatchRecord }` |
| POST | `/records/delete` | `{ "recordId" }` |

**sync 单条 entry 要点（兼容旧字段）：**

```json

  "clientId": "e_xxx",
  "type": "photo",
  "content": "文字",
  "media": [{ "url": "https://...", "kind": "image", "size": 204800 }],

```

## 4. 媒体上传（必须按新契约）

### 4.1 三步

```
POST /media/prepare  →  { mediaId, uploadUrl, method, headers, fields, confirmToken, driver }
     ↓
wx.uploadFile / PUT 到 uploadUrl（带 Authorization；local 时 formData = fields + file）
     ↓
POST /media/confirm  →  { mediaId, confirmToken } → 媒体 DTO（status=active）
```

### 4.2 prepare

```json
{
  "ownerType": "entry",
  "ownerId": "<已存在的 entryId / userId / journeyId …>",
  "kind": "image",
  "mime": "image/jpeg",
  "sizeBytes": 204800,
  "durationSec": 18,
  "sortOrder": 0
}
```

| ownerType | ownerId |
|-----------|---------|
| `entry` | 记录 id |
| `avatar` | 当前 userId |
| `journey_cover` | 旅程 id |
| `guide` / `destination` | 对应 id（预留） |

MIME：图片 `jpeg/png/webp`；音频 `m4a/mp3/aac` 等。图片 ≤10MB，音频 ≤30MB。  
配额不足：`code: QUOTA_EXCEEDED`。

### 4.3 confirm

```json
{ "mediaId": "...", "confirmToken": "...", "durationSec": 18, "width": 4032, "height": 3024 }
```

返回含 `url`、`kind`、`legacyKind`。  
`avatar` / `journey_cover` confirm 后会写回用户头像 / 旅程封面。

### 4.4 本地文件 URL

若 `url` 形如 `/api/v1/files/2026/07/24/xxx.jpg`，展示时请求须带 Bearer。

旧 `GET /media/upload-url` **废弃**，勿新写。

## 5. 模块对象速查（TypeScript 草图）

```ts
type Journey = {
  id: string;
  title: string;
  origin: string;
  destination: string | null;
  coverUrl: string | null;
  startDate: string;
  endDate: string;
  status: 'planned' | 'ongoing' | 'finished';
  displayStatus: 'planning' | 'departing' | 'ongoing' | 'finished';
  themeTags: string[];
  companions: string[];
  budgetAmount: number | null;
  isPublic: boolean;
  days?: number;
  nights?: number;
};

type JourneyStats = {
  placeCount: number;
  recordCount: number;
  expenseTotalCent: number;
  todayPlaceCount: number;
};

type PlanProgress = { checkDone: number; checkTotal: number; pct: number };

type Plan = {
  places: Array<Record<string, unknown>>;
  checks: Array<{ clientId: string; text: string; done: boolean }>;
  budgetEstimate: number;
};

type Entry = {
  id: string;
  clientId: string;
  type: string;
  content: string;
  dayIndex: number;
  recordedAt: string;
  location: { lat: number; lng: number; name: string | null } | null;
  expense: {
    amountCent: number;
    category: string;
    currency: string;
    note: string | null;
  } | null;
  media: Array<{
    id: string;
    kind: 'image' | 'audio';
    url: string;
    sortOrder: number;
    sizeBytes?: number;
  }>;
  audio: { url: string; durationSec: number | null } | null;
  legacy?: { images: string[]; audioUrl: string | null; voice: unknown };
};

type ExpenseSummary = {
  totalCent: number;
  count: number;
  byCategory: Array<{
    category: string;
    amountCent: number;
    ratio: number;
    count: number;
  }>;

};
```

## 6. 错误与枚举

### 6.1 常见错误

| 场景 | 表现 |
|------|------|
| 未登录 / token 失效 | 401 |
| 资源不属于当前用户 | 403 / 404 |
| 参数校验失败 | 400 + message |
| 配额不足 | 400，`code: QUOTA_EXCEEDED` |
| 攻略未就绪 | 400，`code: GUIDE_NOT_READY`（create 时） |
| 生产禁用开发登录 | 403，`DEV_DISABLED` |

### 6.2 主题 / 同行人（英文 key）

- themeTags：`city_walk` `island` `food` `family_kids` `hiking` `culture` `shopping` `relax`
- companions：`solo` `couple` `friends` `family` `with_kids` `pet`（`solo` 不可与其它组合）

## 7. 前端迁移清单（对照旧代码）

| 旧调用 | 新调用 |
|--------|--------|
| 详情 4 连发 GET | `POST /journeys/detail` |
| 统计 6 连发 GET | `POST /stats/dashboard` |
| `GET /journeys?status=` | `POST /journeys/list` |
| `GET /journeys/:id/entries` | `POST /journeys/entries/list` 或 detail.include |
| `GET /journeys/:id/plan` | `POST /journeys/plan/get` |
| `GET /journeys/:id/expense-summary` | `POST /journeys/expense/summary` |
| `GET /stats/*?rangeType=` | `POST /stats/...` body |
| `GET /pois/search?keyword=` | `POST /pois/search` |
| `GET /media/upload-url` | `POST /media/prepare` → upload → confirm |
| 平铺读 `item.title` / `item.totalExpense` | 读 `item.journey.title` / `item.journeyStats.expenseTotalCent` |
| 只认 `kind===photo` | 认 `image` 或 `legacyKind===photo` |

旧接口可作回退；发版后请切新契约。

## 8. 联调最小脚本

```bash
BASE=http://127.0.0.1:3000/api/v1
TOKEN=$(curl -s -X POST $BASE/auth/wechat-login \
  -H 'Content-Type: application/json' \
  -d '{"code":"dev_openid_demo"}' | jq -r .token)

# 列表
curl -s -X POST $BASE/journeys/list \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"page":1,"pageSize":10}' | jq '.list[0].journey.title'

# 详情
curl -s -X POST $BASE/journeys/detail \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"journeyId":"bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002","include":["entries","plan","expense","guide"]}' \
  | jq '{title:.journey.title, n:(.entries|length), exp:.expense.totalCent}'

# 统计
curl -s -X POST $BASE/stats/dashboard \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"rangeType":"all"}' | jq '.data | keys'
```
