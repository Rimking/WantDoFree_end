# 统计模块 · 前端对接文档

> 配套设计：`docs/渡清川_统计模块_后端对照文档.html`  
> 前缀：`/api/v1` · 鉴权：`Authorization: Bearer <token>`  
> `userId` **一律从 token 解析**，禁止前端传入  
> 版本：v1.0 · 2026-07-24

---

## 1. 通用约定

### 1.1 成功响应（本模块）

统计接口成功时返回设计文档约定的包装体（与其它模块「裸 JSON」略有不同，请按本节对接）：

```json
{
  "code": 0,
  "data": { },
  "range": {
    "type": "all",
    "start": null,
    "end": null
  }
}
```

| 字段 | 说明 |
|------|------|
| `code` | `0` 成功 |
| `data` | 业务数据 |
| `range` | 实际生效的时间范围回显 |

### 1.2 错误响应

与全局一致：HTTP 状态码 + body

```json
{
  "code": 400,
  "message": "custom 范围必须同时提供 start 与 end（YYYY-MM-DD）",
  "timestamp": "...",
  "path": "/api/v1/stats/overview"
}
```

| code | HTTP | 含义 |
|------|------|------|
| `401` | 401 | 未登录 / token 失效 |
| `400` | 400 | 参数非法 |
| `404` | 404 | 旅程不存在或非本人 |
| `429` | 429 | 统计接口限流（约 20 次/分钟/用户） |
| `500` | 500 | 内部错误 |

### 1.3 时间范围 Query

| 参数 | 必填 | 说明 |
|------|------|------|
| `rangeType` | 否，默认 `all` | `all` \| `year` \| `month` \| `custom` |
| `start` | `custom` 必填；`year`/`month` 建议传 | 见下表 |
| `end` | `custom` 必填 | `YYYY-MM-DD` |
| `journeyId` | 否 | 限定单旅程（须本人） |
| `status` | 仅 journeys | `ongoing` \| `planning` \| `completed` \| `draft` |

| rangeType | start 示例 | end | 生效区间 |
|-----------|------------|-----|----------|
| `all` | — | — | 不限 |
| `year` | `2025` 或 `2025-01-01` | — | 当年 01-01 ~ 12-31 |
| `month` | `2025-10` | — | 当月 1 日 ~ 月末 |
| `custom` | `2025-08-01` | `2025-10-31` | 闭区间 |

金额一律**分（整数）**，展示时 ÷100。

## 2. 接口一览

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/stats/overview` | 总览 KPI + 洞察文案 |
| `GET` | `/stats/expenses` | 花费：分类 / 日趋势 / 按旅程 |
| `GET` | `/stats/plans` | 准备事项完成率、目的地覆盖、预算执行 |
| `GET` | `/stats/journeys` | 旅程状态分布、天数、地点、完成度分桶 |
| `GET` | `/stats/content` | 内容量：记录 / 图 / 语音 / 字数 / 手帐 |
| `GET` | `/stats/storage` | 配额用量（无 range） |

## 3. GET /stats/overview

```http
GET /api/v1/stats/overview?rangeType=all
GET /api/v1/stats/overview?rangeType=year&start=2025
GET /api/v1/stats/overview?rangeType=custom&start=2025-08-01&end=2025-10-31&journeyId=<uuid>
```

**data**

| 字段 | 类型 | 说明 |
|------|------|------|
| `totalRecords` | number | 有效记录条数 |
| `totalDays` | number | 范围内旅程天数求和（end−start+1） |
| `totalExpense` | number | 花费合计（分） |
| `totalPlaces` | number | 去重地点名数量（来自记录定位） |
| `streakDays` | number | 连续有记录天数 |
| `insight` | string | 如「你已记录 31 条，走过 18 个地方」 |

`rangeType=all` 时服务端会异步刷新 `user_stats_snapshots` 当日快照。

## 4. GET /stats/expenses

```http
GET /api/v1/stats/expenses?rangeType=year&start=2025
```

**data**

| 字段 | 类型 | 说明 |
|------|------|------|
| `total` | number | 总花费（分） |
| `currency` | string | 固定 `CNY` |
| `byCategory` | `{ category, amount, ratio }[]` | 分类占比 |
| `trend` | `{ date, amount }[]` | 按日 |
| `byJourney` | `{ journeyId, name, amount, ratio }[]` | 按旅程 |

**category 规范值**（读出英文 key）：

`food` \| `stay` \| `transport` \| `ticket` \| `shopping` \| `other`  

> 设计文档中的 `hotel` 已归一为 `stay`。

## 5. GET /stats/plans

```http
GET /api/v1/stats/plans?rangeType=all
GET /api/v1/stats/plans?journeyId=<uuid>
```

**data**

| 字段 | 类型 | 说明 |
|------|------|------|
| `preTripDoneRate` | number 0~1 | 准备事项勾选率（checklist） |
| `destinationCoverage` | number 0~1 | 已拜访目的地 / 计划目的地 |
| `planPlaces` | number | destinations 数（未软删） |
| `visitedPlaces` | number | 记录定位名与目的地同名的数量 |
| `planVsActualGap` | number \| null | planPlaces − visitedPlaces |
| `budgetExecutionRate` | number \| null | 已花 / 旅程预算合计；无预算为 `null` |

---

## 6. GET /stats/journeys

```http
GET /api/v1/stats/journeys?rangeType=all
GET /api/v1/stats/journeys?rangeType=all&status=ongoing
```

**data**

| 字段 | 类型 | 说明 |
|------|------|------|
| `totalByStatus` | object | `{ ongoing, planning, completed, draft }` |
| `totalDays` | number | 范围内（可叠加 status 筛选）旅程天数和 |
| `totalPlaces` | number | 去重地点数 |
| `completionDist` | number[4] | 准备完成度分桶：`[0~25, 25~50, 50~75, 75~100]` 的旅程数 |

**状态映射（持久化 → 统计）**

| 统计字段 | 后端 status |
|----------|-------------|
| `ongoing` | `ongoing` |
| `planning` | `planned`（含展示态 planning/departing） |
| `completed` | `finished` |
| `draft` | 暂无旅程草稿，恒为 `0` |

## 7. GET /stats/content

```http
GET /api/v1/stats/content?rangeType=year&start=2025
```

**data**

| 字段 | 类型 | 说明 |
|------|------|------|
| `recordCount` | number | 记录条数 |

| `photoCount` | number | 图片 media 张数 |
| `voiceSeconds` | number | 语音总秒数（优先 payload.durationSec） |
| `wordCount` | number | 文字总字数（含中文按字符计） |
| `handbookCount` | number | 已生成攻略/手帐的旅程数 |

## 8. GET /stats/storage

```http
GET /api/v1/stats/storage
```

无 Query。读当前用户配额。

**data**

```json
{
  "photo": { "used": 18, "limit": 200, "ratio": 0.09 },
  "voice": { "usedSeconds": 48, "limitSeconds": 7200, "ratio": 0.0067 }
}
```

前端：`ratio ≥ 0.85` 展示警示态（金黄→珊瑚）。

## 9. TypeScript 类型（建议）

```ts
export type StatsRangeType = 'all' | 'year' | 'month' | 'custom';

export interface StatsRange {
  type: StatsRangeType;
  start: string | null;
  end: string | null;
}

export interface StatsResponse<T> {
  code: 0;
  data: T;
  range: StatsRange;
}

export interface StatsOverview {
  totalRecords: number;
  totalDays: number;
  totalExpense: number;
  totalPlaces: number;
  streakDays: number | null;
  insight: string;
}

export interface StatsExpenses {
  total: number;
  currency: string;
  byCategory: { category: string; amount: number; ratio: number }[];
  trend: { date: string; amount: number }[];
  byJourney: {
    journeyId: string;
    name: string;
    amount: number;
    ratio: number;
  }[];
}

export interface StatsPlans {
  preTripDoneRate: number;
  destinationCoverage: number;
  planPlaces: number;
  visitedPlaces: number;
  planVsActualGap: number | null;
  budgetExecutionRate: number | null;
}

export interface StatsJourneys {
  totalByStatus: {
    ongoing: number;
    planning: number;
    completed: number;
    draft: number;
  };
  totalDays: number;
  totalPlaces: number;
  completionDist: number[] | null;
}

export interface StatsContent {
  recordCount: number;
  avgPerDay: number;
  photoCount: number;
  voiceSeconds: number;
  wordCount: number;
  handbookCount: number | null;
}

export interface StatsStorage {
  photo: { used: number; limit: number; ratio: number };
  voice: {
    usedSeconds: number;
    limitSeconds: number;
    ratio: number;
  };
}
```

## 11. 数据表

| 表 | 用途 |
|----|------|
| 现有 `journeys` / `entries` / `expenses` / `locations` / `media` / `destinations` / `checklist_items` / `guides` / `users` | 实时聚合 |
| **新增** `user_stats_snapshots` | 日快照：`userId+date` 唯一；字段含 totalRecords / totalDays / totalPlaces / streakDays / totalExpense |

开发环境 `synchronize=true` 自动建表；生产请走迁移。
