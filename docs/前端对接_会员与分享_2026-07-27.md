# 渡清川 · 会员与分享 前端对接文档

> 日期：2026-07-27 · 对齐后端设计 `渡清川_会员与分享_后端设计_2026-07-27.md`  
> Base：`/api/v1` · 鉴权：`Authorization: Bearer <token>`（标明 Public 除外）  
> 数字：免费 **50 张 / 30 分钟**；会员 **300 张 / 180 分钟**  
> 金额：**分**；支付本期 **mock**（`POST .../pay`），正式微信回调为 P1

配套：UI 设计稿 / handoff / PRD；本地图片见《前端配合_本地图片访问说明》。

---

## 0. 前端必读 Diff（相对旧实现）

| 项 | 说明 |
|----|------|
| 会员态 | 用 `GET /membership/me`（或别名 `/membership/status`），勿用旧 `/orders` 买会员 |
| 首月 ¥9 | 看 `me.firstMonthEligible`；下单价以 `createOrder.amountCent` / `firstMonthApplied` 为准 |
| 续费天数 | 服务端在原 `expireAt` 上**顺延**，不是从今天重算覆盖 |
| 水印 | 一律读 `exportPolicy.watermark` / `maxResolution`，前端勿伪造无水印 |
| 邀请 | 新接口 `/invite/code|stats|accept`；开通会员后服务端自动发奖 |
| 分享 | `POST /shares` 已带 `exportPolicy` 与 `channels.saveImage/poster` 水印字段 |

## 1. 会员

### 1.1 `GET /membership/plans`（Public）

```json
[
  {
    "code": "monthly",
    "name": "连续包月",
    "priceCent": 1800,
    "effectivePriceCent": 900,
    "periodDays": 30,
    "autoRenew": true,
    "tag": "首月特惠",
    "firstMonthDiscountCent": 900
  },
  { "code": "yearly", "priceCent": 12800, "periodDays": 365, "autoRenew": true, "tag": "主推" },
  { "code": "yearly_once", "priceCent": 16800, "periodDays": 365, "autoRenew": false }
]
```

未登录时 `effectivePriceCent` 按「可享首月」展示；**真实扣款**以下单响应为准。

### 1.2 `GET /membership/me` · 别名 `GET /membership/status`

```json
{
  "plan": "free" | "pro",
  "status": "FREE" | "ACTIVE" | "EXPIRED",
  "displayStatus": "FREE" | "ACTIVE" | "EXPIRED",
  "expireAt": "ISO|null",
  "autoRenew": false,
  "memberSinceAt": "ISO|null",
  "daysLeft": 12,
  "nearExpire": false,
  "firstMonthEligible": true,
  "benefits": ["photo_50", "voice_30min", "basic_templates"],
  "exportPolicy": {
    "watermark": true,
    "watermarkText": "渡清川·免费版",
    "maxResolution": 720
  },
  "quota": {
    "photo": { "used": 12, "quota": 50, "remaining": 38 },
    "voiceSec": { "used": 120, "quota": 1800, "remaining": 1680, "unit": "second" }
  },
  "pendingOrderNo": null
}
```

| UI | 字段 |
|----|------|
| 未开通标签 | `status===FREE` 且无 `memberSinceAt` |
| 会员角标 / 到期日 | `ACTIVE` + `expireAt` / `daysLeft` |
| 金色临期条 | `nearExpire===true`（≤7 天） |
| 挽回入口 | `status===EXPIRED` 或曾开通已降级 |
| 权益勾选 | `benefits[]` |
| 配额卡 | `quota` 或 `GET /me/quota` |

会员 `benefits` 含：`photo_300`、`voice_180min`、`ai_organize`、`export_1080p`、`no_watermark`、`premium_templates`、`multi_device`、`map_style`。

### 1.3 下单 → mock 支付 → 轮询

```http
POST /membership/orders
{ "planCode": "monthly" | "yearly" | "yearly_once", "couponId"? }

→ {
  "orderNo": "...",
  "amountCent": 900,
  "firstMonthApplied": true,
  "mockPayToken": "mock_...",
  "periodDays": 30,
  "autoRenew": true,
  "expireAt": "订单关单时限"
}

POST /membership/orders/{orderNo}/pay     # 开发期 mock
GET  /membership/orders/{orderNo}       # 轮询 status=paid
POST /membership/orders/{orderNo}/cancel
PATCH /membership/renewal  { "autoRenew": false }
POST /membership/refund    { "orderNo"? }
```

### 1.4 `GET /membership/winback`（stub）

过期 ≥3 天：`available:true` + 展示用券；**不实扣**。正式核销 P1。

## 2. 分享

### 2.1 `GET /share/export-policy`（面板红绿标）

```json
{ "watermark": true, "watermarkText": "渡清川·免费版", "maxResolution": 720 }
```

会员 ACTIVE：`watermark:false`，`maxResolution:1080`。

### 2.2 `POST /shares`

```json
// req
{ "journeyId": "...", "guideId"? , "visibility"? : "public"|"unlisted" }

// res
{
  "token": "...",
  "sharePath": "/pages/ShareView/ShareView?t=...",
  "exportPolicy": { "watermark": true, "watermarkText": "渡清川·免费版", "maxResolution": 720 },
  "channels": {
    "friend":  { "title", "path", "image" },
    "moments": { "title", "path", "image" },
    "link":    { "url" },
    "poster":  { "title", "cover", "path", "watermark", "watermarkText", "maxResolution" },
    "saveImage": { "watermark", "watermarkText", "maxResolution" }
  }
}
```

| 渠道 | 前端动作 |
|------|----------|
| 微信好友 | `onShareAppMessage` 用 `channels.friend` |
| 朋友圈 | `onShareTimeline` 用 `channels.moments` |
| 复制链接 | `channels.link.url` |
| 保存图片 / 生成海报 | Canvas 本地出图；**按 exportPolicy 加水印与分辨率**（服务端暂不出 PNG） |

公开页：`GET /shares/:token`（Public）亦含 `exportPolicy`。  
归因：`POST /shares/:token/view` `{ viewerId? }`。  
统计：`GET /me/share-stats`。  
埋点（可选）：`POST /share-events`。

## 3. 邀请有礼

### 3.1 `GET /invite/code`

```json
{
  "code": "BDE4C43E",
  "sharePath": "/pages/Invite/Invite?code=BDE4C43E",
  "perInviteDays": 30,
  "threshold": 3,
  "bonusDays": 365
}
```

### 3.2 `GET /invite/stats`

```json
{
  "code": "...",
  "invitedCount": 1,
  "registeredCount": 2,
  "threshold": 3,
  "totalRewardDays": 30,
  "bonusGranted": false,
  "nextMilestone": { "need": 2, "rewardDays": 365 },
  "records": [
    { "inviteeId", "nickname", "status": "REGISTERED|REWARDED", "rewardDays", "rewardedAt", "createdAt" }
  ]
}
```

### 3.3 `POST /invite/accept`

```json
{ "code": "BDE4C43E" }
→ { "ok": true, "alreadyBound": false, "status": "REGISTERED", "inviterId": "..." }
```

- 自邀 → 400  
- 被邀请人**首次 mock 支付开通会员**后，服务端自动：双方各 +30 天；满 3 人邀请人再 +365 天  

建议：新用户登录后若 URL 带 `code=`，调一次 `accept`。

## 4. 页面接线建议

| 页面 | 接口 |
|------|------|
| 会员中心免费态 | `plans` + `me` |
| 会员中心会员态 | `me`（quota/daysLeft/nearExpire） |
| 确认订单 / 支付中 | `orders` → `pay` → 轮询 `orders/:id` |
| 管理订阅 | `PATCH /membership/renewal` |
| 流失挽回 | `winback` + `me` |
| 「我的」入口 | `me.status` / `expireAt` |
| 配额满 CTA | `me.quota` 或 `/me/quota` |
| 分享面板 | `export-policy` 或创建 `shares` |
| 邀请页 / 进度 | `invite/code` + `invite/stats` |
