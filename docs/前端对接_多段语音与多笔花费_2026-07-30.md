## 1. 花费 `expenses[]`

### 规则

| 规则 | 说明 |
|------|------|
| 优先 | 有 `expenses` 时以数组为准 |
| 兼容 | 单对象 `expense` 仍可写；读侧 `expense.amountCent` = **合计**，`category` = **首笔** |
| 清空 | PATCH：`expenses: []` 或 `expenses: null` 或 `expense: null` |
| 校验 | 每笔 `amountCent ≥ 1`；`category`：`food\|stay\|transport\|ticket\|shopping\|other` |
| 上限 | 单条记录最多 **20** 笔 |

### sync 写

`POST /journeys/entries/sync`

```json
{
  "journeyId": "...",
  "entries": [{
    "clientId": "rec-xxx",
    "content": "夜市",
    "expenses": [
      { "amountCent": 6800, "category": "food", "currency": "CNY" },
      { "amountCent": 1200, "category": "transport" },
      { "amountCent": 5000, "category": "ticket" }
    ]
  }]
}
```

仍可只传单笔 `expense`（旧客户端）。

### PATCH 写

`POST /records/update`（或 `PATCH /records/:recordId`）

```json
{
  "recordId": "...",
  "expenses": [
    { "amountCent": 6800, "category": "food" },
    { "amountCent": 5000, "category": "ticket" }
  ]
}
```

- 传入 `expenses`：**整表覆盖**该记录花费  
- 只传 `expense`：覆盖为**一笔**  
- 二者都未传：不改花费

### 读模型（list / detail / update 响应）

平铺与模块化均含：

```json
{
  "expenses": [
    {
      "id": "...",
      "amountCent": 6800,
      "category": "food",
      "currency": "CNY",
      "note": null,
      "sortOrder": 0
    }
  ],
  "expense": {
    "amountCent": 13000,
    "category": "food",
    "currency": "CNY",
    "note": null
  }
}
```

模块化 `toEntryModule` 同样返回 `expenses` + 兼容 `expense`。

## 2. 多段语音

### 推荐写法（方案 A）

语音落在 `media[]`，`kind: "audio"`（兼容 `voice`），带 `durationSec`、`sortOrder`。  
`voice` / `audio` / `audioUrl` 仍为**首段**兼容字段。

### sync 写

```json
{
  "clientId": "rec-xxx",
  "media": [
    { "url": "https://cdn/a.jpg", "kind": "image", "sortOrder": 0 },
    { "url": "https://cdn/v1.mp3", "kind": "audio", "durationSec": 12, "sortOrder": 1 },
    { "url": "https://cdn/v2.mp3", "kind": "audio", "durationSec": 8, "sortOrder": 2 }
  ],
  "voice": { "url": "https://cdn/v1.mp3", "durationSec": 12 },
  "voices": [
    { "url": "https://cdn/v1.mp3", "durationSec": 12 },
    { "url": "https://cdn/v2.mp3", "durationSec": 8 }
  ]
}
```

`voices[]` 会并入 audio media（与 `media` 按 url 去重）。

### PATCH 写（覆盖语义）

优先顺序：`audios` > `voices` > `audioUrl`。

```json
{
  "recordId": "...",
  "audios": [
    { "url": "https://cdn/v1.mp3", "durationSec": 12 },
    { "url": "https://cdn/v3.mp3", "durationSec": 5 }
  ]
}
```

| 传参 | 行为 |
|------|------|
| `audios` / `voices` 数组 | **只替换全部语音**，不动图片 |
| `audios: []` / `null` | 清空全部语音 |
| 仅 `audioUrl` | 旧行为：清空后写 0/1 段 |
| 仅 `images` | **只动图片**，不清语音 |

单段时长 ≤ 300 秒。

### 读模型

```json
{
  "voices": [
    { "url": "...", "durationSec": 12, "size": 0, "sortOrder": 0 },
    { "url": "...", "durationSec": 8, "size": 0, "sortOrder": 1 }
  ],
  "voice": { "url": "...", "durationSec": 12 },
  "audioUrl": "...",
  "audioDuration": 12,
  "media": [ /* 含全部 image + audio，按 sortOrder */ ]
}
```

模块化另有 `audio`（首段）与 `voices[]`。

## 3. 花费汇总（P1 已对齐）

`POST /journeys/expense/summary` · `POST /me/expense/summary` · `POST /stats/expenses`

| 字段 | 语义 |
|------|------|
| `totalCent` | 所有花费行金额之和 |
| `count` | **花费笔数**（expenses 行数） |
| `byCategory[].count` | 该分类笔数 |
| `byCategory[].amountCent` | 该分类金额之和 |

`/stats/expenses` 现也返回顶层 `count` 与 `byCategory[].count`。
