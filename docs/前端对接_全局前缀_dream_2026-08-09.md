# 前端对接 · 全局前缀 api → dream（2026-08-09）

> **破坏性变更**：所有业务接口路径前缀由 `/api` 改为 `/dream`。  
> 版本号仍为 `v1`。

---

## 1. 变更对照

| 项 | 旧 | 新 |
|----|----|----|
| 全局前缀 | `/api` | `/dream` |
| 业务 Base | `/api/v1` | `/dream/v1` |
| 列表示例 | `POST /api/v1/journeys/list` | `POST /dream/v1/journeys/list` |
| 本地文件 | `/api/v1/files/...` | `/dream/v1/files/...` |
| 本地上传 | `/api/v1/media/local-upload` | `/dream/v1/media/local-upload` |
| Swagger | `/api/docs` | `/dream/docs` |

路径其余部分（如 `/journeys/list`、`/auth/wechat-login`）**不变**。

---

## 2. 前端必改

1. **`VITE_API_BASE`**（或等价配置）  
   - 示例：`http://192.168.1.80:3000/dream/v1`  
   - 本地：`http://localhost:3000/dream/v1`
2. 所有硬编码的 `/api/v1` 字符串改为 `/dream/v1`（若有）。
3. 媒体展示逻辑：新 URL 走 `/dream/v1/files/`；历史数据若仍是 `/api/v1/files/`，建议兼容解析（小程序侧已做兼容）。
4. 改完后需**重新编译**小程序（`dev:mp-weixin`），真机勿再用旧 Base。

---

## 3. 验收

- [ ] 登录：`POST /dream/v1/auth/wechat-login` 200  
- [ ] 旅程列表：`POST /dream/v1/journeys/list` 200  
- [ ] 旧地址 `/api/v1/...` 应 404（已不再挂载）  
- [ ] 文档：`http://localhost:3000/dream/docs`
