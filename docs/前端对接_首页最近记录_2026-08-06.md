# 前端对接 · 首页最近记录（2026-08-06）

> **Base**：`/api/v1`  
> **鉴权**：`Authorization: Bearer <token>`（JWT）  
> **用户身份**：**勿在 body 传 `userId`**。后端从 JWT 解析当前登录用户，只返回该用户的记录（防越权）。

---

## 1. 为什么不需要传 userId

| 方式 | 说明 |
|------|------|
| ✅ JWT | 登录后请求头带 token，服务端 `CurrentUser.id` = 当前用户 |
| ❌ body.userId | 客户端可伪造查别人数据；本项目全局禁止 |

与其它接口一致：`/journeys/list`、`/journeys/entries/list`、`/me` 等均不传 `userId`。

---

## 2. 接口

推荐首页使用：

```http
POST /records/recent
Authorization: Bearer <token>
Content-Type: application/json

{}
```

同构别名（效果相同）：

```http
POST /journeys/entries/recent
```

### 2.1 请求 Body

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `limit` | number | 否 | 条数，默认 `10`，范围 `1–10`；超过返回「参数错误」 |

**不接受** `userId` / `journeyId`：本接口按**登录用户 + 时间**取最近记录，不按计划/旅程筛选。

### 2.2 排序与条数

- 时间键：`COALESCE(recordedAt, createdAt)` 倒序（无记录发生时间则用创建时间）
- 固定上限：**最多 10 条**；多了不管
- 范围：该用户名下**全部旅程**的记录混排，仅看时间

### 2.3 响应

```json
{
  "list": [
    {
      "id": "uuid",
      "clientId": "e_xxx",
      "type": "photo",
      "content": "丶这一条u呀",
      "dayIndex": 1,
      "recordedAt": "2026-08-05T14:00:18.000Z",
      "createdAt": "2026-08-05T14:00:18.000Z",
      "syncVersion": 1,
      "location": null,
      "expenses": [],
      "expense": null,
      "media": [
        {
          "id": "…",
          "kind": "image",
          "url": "https://…",
          "thumbUrl": null,
          "sortOrder": 0
        }
      ],
      "voices": [],
      "audio": null,
      "journeyId": "uuid",
      "journeyTitle": "123"
    }
  ],
  "limit": 10,
  "total": 10
}
```

| 字段 | 说明 |
|------|------|
| `list` | Entry 模块化结构（与 `entries/list` / detail.entries 同构） |
| `list[].journeyId` | 所属旅程，点击跳转编辑/详情用 |
| `list[].journeyTitle` | 旅程标题（卡片副文案可选） |
| `limit` | 本次请求上限 |
| `total` | 实际返回条数（≤ limit） |

封面：取 `media` 中首张 `kind=image`（或兼容 `photo`）的 `url`；无图则前端按类型用渐变底。

类型展示：用 `type`（`text`/`photo`/`voice`/`location`/`expense`），与现有首页 `resolveRecordType` 一致。

---

## 3. 前端接入建议

```ts
// 伪代码
const { list } = await post('/records/recent', {})
// list 已按时间倒序，直接喂首页「最近记录」横滑
```

- 已登录才请求；未登录不调或展示空态  
- 「查看全部」仍进记录中心（全量/按旅程），不必改本接口  
- 点击卡片：用 `journeyId` + `id`（recordId）进编辑页  

---

## 4. 错误

| 场景 | HTTP | code / message |
|------|------|----------------|
| 未登录 / token 无效 | 401 | 鉴权失败 |
| `limit` 非法（如 99） | 400 | `40001` / 参数错误 |

---

## 5. 与既有接口关系

| 接口 | 用途 |
|------|------|
| `POST /records/recent` | **首页**最近 10 条（本文件） |
| `POST /journeys/entries/list` | 某一旅程下全部记录（需 `journeyId`） |
| `POST /journeys/entries/sync` | 新增记录 |
| `POST /records/update` | 编辑单条 |

---

## 6. 联调验收

- [ ] 登录用户 A：返回其记录，按时间新→旧，条数 ≤ 10  
- [ ] 用户 B 的 token：看不到 A 的数据  
- [ ] body 不传任何字段可成功  
- [ ] `limit: 5` 最多 5 条；`limit: 99` → 参数错误  
- [ ] 卡片能取到封面图 / 文案 / `journeyId` 可跳转
