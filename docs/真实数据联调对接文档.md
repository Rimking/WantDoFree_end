## 1. 联调前准备

| 步骤 | 动作 |
|------|------|
| 1 | 后端启动：`npm run start:dev`（端口 3000） |
| 2 | 确认种子已写入：`npm run seed:demo`（可重复执行） |
| 3 | 前端 `USE_MOCK=false`，`API_BASE=http://localhost:3000/api/v1`（真机改局域网 IP） |
| 4 | 小程序 AppID 与后端一致：`wx1daa98e09ce44d56` |
| 5 | 成功响应是**裸 JSON**；请求头带 `Authorization: Bearer <token>` |

### 登录拿种子账号（必做）

```http
POST /api/v1/auth/wechat-login
Content-Type: application/json

{"code":"dev_openid_demo"}
```

> 非生产环境：即使已配真实微信密钥，该 code 仍映射种子用户。  
> 真机 `wx.login` 拿到的是新 openid，**看不到**这套假数据；联调 UI 请用上面的 code。

响应要点：

```json
{
  "token": "eyJ...",
  "user": {
    "id": "aaaaaaaa-1111-1111-1111-111111111111",
    "openid": "dev_openid_demo",
    "nick": "途记演示",
    "nickname": "途记演示",
    "plan": "free"
  }
}
```

本地持久化 `token`，后续所有接口带：

```http
Authorization: Bearer <token>
```

## 3. 按页面联调（推荐顺序）

### Step A · 登录 & 我的

| 页面 | 接口 | 期望 |
|------|------|------|
| 启动 / 授权 | `POST /auth/wechat-login` | 拿到 token + 途记演示 |
| 我的 | `GET /me` | nick/nickname=途记演示 |
| 配额 | `GET /me/quota` | photo / voiceSec |
| 个人资料编辑 | `GET /user/profile` | 昵称/头像/性别/生日/所在地/身份等 |
| 年度预算 | `GET /me/budget?year=2026` | amountCent=3000000 |

### Step B · 旅程首页（三态 Tab / 展示态）

```http
GET /journeys
Authorization: Bearer <token>
```

或按持久化三态 / 展示态：

```http
GET /journeys?status=planned
GET /journeys?status=ongoing
GET /journeys?status=finished
GET /journeys?displayStatus=departing
GET /journeys?displayStatus=planning
```

列表项关键字段（已双字段兼容）：

| 接口字段 | 前端可用作 |
|----------|------------|
| `id` | 路由 journeyId |
| `clientId` | 本地幂等键 |
| `origin` / `destination` | 「上海 → 杭州」文案 |
| `status` | 持久化：planned / ongoing / finished |
| `displayStatus` | 展示态：planning / departing / ongoing / finished |
| `planProgress` | 卡片底栏完成度 0–100 |
| `confirmedCount` | 规划中「已定」数 |
| `todayPlaceCount` | 进行中「今日地点」（近似） |
| `themeTags` / `themes` | 主题标签 |
| `budgetAmount` / `budgetLimit` | 预算 |
| `coverUrl` / `cover` | 封面 |
| `days` / `nights` | N天M晚 |
| `expenseTotal` / `totalExpenseCent` | 已花 |
| `recordCount` / `entryCount` | 记录数 |
| `placeCount` | 地点数（来自 plan.places） |

**期望条数（种子）**：`status=planned` 2（厦门 departing + 三亚 planning）、ongoing 1、finished 2。  
厦门（`…0001`）：`displayStatus=departing`，`planProgress=50`（checks 2/4）。  
三亚（`…0005`）：`displayStatus=planning`。

### Step C · 旅程详情 + 计划

以杭州为例（`…0002`）：

```http
GET /journeys/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002
GET /journeys/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002/plan
```

计划响应含 `places[]` / `checks[]`（每项同时有 `id` 与 `clientId`）。

切换状态（仅相邻）：

```http
POST /journeys/{id}/status
{"target":"ongoing"}
```

### Step D · 时间线记录（京都优先）

```http
GET /journeys/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002/entries
```

每条为**聚合体**，含：

- `dayIndex`（按 startDate 算，从 1 起）
- `location` / `expense` / `media[]` / `voice`
- `expense.category` 英文 key；`amount` 与 `amountCent` 同值

京都时间线样例（库内真实）：

| day | clientId | type | 内容摘要 |
|-----|----------|------|----------|
| 1 | r_ky_d1_photo | photo | 清水寺红叶 + 定位 |
| 1 | r_ky_d1_food | photo | 亲子丼 + 花费 + 语音 |
| 1 | r_ky_d1_voice | voice | 伏见稻荷 |
| 1 | r_ky_d1_stay | expense | 町屋 ¥680 |
| 2 | r_ky_d2_* | … | 地铁 / 金阁寺 / 伴手礼 / 鸭川 |
| 3 | r_ky_d3_* | … | 岚山 / 寿喜烧 |

写入仍走：

```http
POST /journeys/{id}/entries/sync
{"entries":[{ "clientId":"...", "content":"...", "media":[...], "location":{...}, "expense":{...} }]}
```

### Step E · 花费

单旅程：

```http
GET /journeys/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002/expense-summary
```

期望：`totalCent=167100`，`byCategory` 含 food/stay/transport/ticket/shopping。

记账 Tab（全年）：

```http
GET /me/expense-summary?year=2025
```

期望：能看到大理 + 冰岛 + 京都的 `byJourney`；`journeyCount` / `destCount` / `byMonth` 有数据。

年度预算页：

```http
GET /me/budget?year=2025
PATCH /me/budget
{"year":2025,"amountCent":5000000}
```

### Step F · 一键攻略 / 分享

**京都（已有缓存）**

```http
GET /journeys/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002/guide/check
→ {"canGenerate":true,...}

GET /journeys/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002/guide
→ exists:true，含 days/nights/cities/cityCount/themeLabel/highlights/byCategory
```

**曼谷（无攻略）**

```http
GET /journeys/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0001/guide/check
→ 记录少 / 无图无定位 → canGenerate:false（测禁用按钮）

GET /journeys/...0001/guide
→ 404，code=GUIDE_NOT_FOUND，exists:false
```

收藏（按旅程，推荐）：

```http
POST /journeys/{id}/guide/favorite
```

分享：

```http
POST /share-events
{"journeyId":"bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002","channel":"timeline"}
```

> `guideId` 可省略；`timeline` 会规范为 `moments`。

### Step G · 草稿箱

```http
GET /drafts
```

种子含：曼谷下一条 entry 草稿 + 「冲绳潜水」旅程草稿。

## 4. 固定 ID 速查（复制用）

```text
USER_ID     = aaaaaaaa-1111-1111-1111-111111111111
J_BANGKOK   = bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0001
J_KYOTO     = bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002
J_ICELAND   = bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0003
J_DALI      = bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0004
G_KYOTO     = dddddddd-dddd-dddd-dddd-dddddddd0002
G_ICELAND   = dddddddd-dddd-dddd-dddd-dddddddd0003
G_DALI      = dddddddd-dddd-dddd-dddd-dddddddd0004
```

本地 curl 冒烟：

```bash
TOKEN=$(curl -s http://localhost:3000/api/v1/auth/wechat-login \
  -H 'Content-Type: application/json' \
  -d '{"code":"dev_openid_demo"}' | jq -r .token)

curl -s http://localhost:3000/api/v1/journeys \
  -H "Authorization: Bearer $TOKEN" | jq 'map({title,status,expenseTotal,recordCount})'

curl -s http://localhost:3000/api/v1/journeys/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002/entries \
  -H "Authorization: Bearer $TOKEN" | jq 'length'

curl -s http://localhost:3000/api/v1/journeys/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002/guide \
  -H "Authorization: Bearer $TOKEN" | jq '{title:.payload.meta.title,cities,totalExpense,isFavorited}'
```

## 6. 常见坑

| 现象 | 原因 | 处理 |
|------|------|------|
| 登录后列表空 | 用了真实 `wx.login` code | 联调改用 `dev_openid_demo` |
| 401 | 未带 Bearer | 登录后写入请求拦截器 |
| 攻略 404 | 曼谷本来就没有 guide | 先 check，再决定是否 generate |
| 字段对不上 | 前端本地 DEMO 字段名 | 看双字段：themes↔themeTags、cover↔coverUrl、amount↔amountCent、pet↔with_pet |
| 真机连不上 | localhost | `API_BASE` 改电脑局域网 IP，并关防火墙 |
