# 前端对接 · 旅程列表筛选（journeys/list）（2026-08-09）

> **Base**：`/api/v1` · JWT；**勿传 userId**  
> 接口：`POST /journeys/list`  
> 用途：首页旅程卡片列表（按类型 / 关键词 / 行程时间筛选）

---

## 1. 请求

```http
POST /journeys/list
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "type": 1,
  "keyword": "杭州",
  "startTime": "2026-08-01",
  "endTime": "2026-08-31",
  "page": 1,
  "pageSize": 20,
  "modular": true
}
```

### 1.1 新增筛选字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | number | 否 | **不传=全部**；`1` 进行中；`2` 即将出发；`3` 规划中；`4` 已完成 |
| `keyword` | string | 否 | 模糊匹配**计划名称**（`journey.title`） |
| `startTime` | string | 否 | 行程区间起，建议 `YYYY-MM-DD`（也认 ISO 前缀日期） |
| `endTime` | string | 否 | 行程区间止，建议 `YYYY-MM-DD` |

### 1.2 `type` 与展示态对应

| type | 含义 | 后端 `displayStatus` |
|------|------|----------------------|
| （不传） | 全部 | — |
| `1` | 进行中 | `ongoing` |
| `2` | 即将出发 | `departing` |
| `3` | 规划中 | `planning` |
| `4` | 已完成 | `finished` |

> `type` 优先于旧字段 `displayStatus` / `status`。旧字段仍兼容，新首页请只用 `type`。

### 1.3 时间区间规则

对旅程自身的 `startDate` / `endDate` 做**区间交集**：

- 有 `startTime`：排除 `endDate < startTime` 的旅程  
- 有 `endTime`：排除 `startDate > endTime` 的旅程  
- 两者都传且 `startTime > endTime` → `40001` 参数错误  

只传一端也可以（开放区间）。

### 1.4 分页（原有）

| 字段 | 默认 | 说明 |
|------|------|------|
| `page` | 1 | 页码 |
| `pageSize` | 20 | 每页条数，最大 100 |
| `modular` | true | 模块化卡片结构 |

筛选在分页**之前**完成：`total` = 筛后总数。

---

## 2. 响应

`list[]` 为**扁平卡片对象**（非模块嵌套）。字段见 [`前端对接_旅程列表卡片扁平化_2026-08-09.md`](./前端对接_旅程列表卡片扁平化_2026-08-09.md)。

```json
{
  "list": [ { "id": "...", "title": "...", "displayStatus": "ongoing", "pct": 0 } ],
  "total": 12,
  "page": 1,
  "pageSize": 20
}
```

---

## 3. 示例

全部：

```json
{}
```

仅进行中：

```json
{ "type": 1 }
```

规划中 + 关键词「苏州」+ 八月行程：

```json
{
  "type": 3,
  "keyword": "苏州",
  "startTime": "2026-08-01",
  "endTime": "2026-08-31"
}
```

---

## 4. 联调验收

- [ ] 不传 `type` 返回各展示态混合列表  
- [ ] `type=1|2|3|4` 分别只含对应 `journey.displayStatus`  
- [ ] `keyword` 仅按计划名称（title）模糊命中  
- [ ] `startTime`/`endTime` 按行程日期交集过滤  
- [ ] `page`/`pageSize` 在筛选后分页，`total` 正确
