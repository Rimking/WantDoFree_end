# 旅程列表卡片 · 接口字段使用说明

> 范围：`POST /journeys/list` 在 **我的旅程**（`JourneyList`）与共用大卡 `JourneyListCard` 上的实际消费情况。  
> 首页进行中列表共用同一张卡，字段口径一致。  
> 统计日期：2026-08-09（以当前前端代码为准）。  
> **2026-08-09 起列表已改为扁平单对象**，前端请对照 [`前端对接_旅程列表_2026-08-09.md`](./前端对接_旅程列表_2026-08-09.md)；下文为字段用途背景。

## 1. 响应结构（现行）

```json
{
  "list": [
    {
      "id": "...",
      "title": "...",
      "coverUrl": null,
      "origin": null,
      "destination": null,
      "startDate": "2026-08-10",

      "companions": [],
```

## 2. 列表页实际用到的字段（建议后端保留）

### 2.1 `journey`（主体）

| 字段 | 用途 | 出现位置 |
|------|------|----------|
| `id` | 跳转详情/计划/游记、删除/结束、封面 fallback | 卡片交互、路由 |
| `title` | 卡片标题；结束弹窗文案 | 卡片、结束确认 |
| `cover` / `coverUrl` | 封面图（映射为 `Journey.cover`） | 卡片顶部 |
| `origin` | 状态推导辅助；已完成态副文案短地名 | `resolveJourneyStatus` 间接；`shortDestination` |
| `destination` | 已完成态副文案短地名 | `shortDestination` |
| `startDate` | 展示状态、Day 进度、倒计时、「MM.DD 出发」 | 徽章 / 进度 / 副文案 |
| `endDate` | 展示状态、行程总天数 | 同上 |
| `status` / `displayStatus` | 展示态：进行中 / 即将出发 / 规划中 / 已完成（优先 `displayStatus`） | 状态徽章、按钮文案、时间轴色 |
| `companions` | 进行中副文案「N 人」 | 卡片副行 |
| `createdAt` | 左侧时间轴「今天 / 昨天 / M.D · 状态」 | `JourneyList` 时间轴标签 |

### 2.2 `journeyStats`（统计，映射后覆盖/补齐 journey 上的统计）

| 字段 | 映射到 | 用途 |
|------|--------|------|
| `placeCount` | `Journey.placeCount` | 「N 地点 / 想去 / 今日已到访」等文案（列表无本地 plan 时依赖此项） |
| `recordCount` | `Journey.recordCount` | 已完成态：「N 条记录」 |
| `expenseTotalCent` | `Journey.expenseTotal` | 「¥ x」花费展示 |

### 2.3 `planProgress`（准备进度）

| 字段 | 用途 |
|------|------|
| `checkDone` | 即将出发：剩余待办 = `checkTotal - checkDone` |
| `checkTotal` | 同上；`planPct` 判断是否有检查项 |
| `pct` | 规划中：徽章 `N%`、进度条、副文案「规划 N%」 |

## 3. 已返回但列表页未使用的字段

### 3.1 整模块未用

| 模块 | 说明 |
|------|------|
| `handbook` | 含 `phase` / `recordCount` / `minRecords` / `hasGuide` / `guideId` / `templateId` 等；`mapJourneyListItem` **直接丢弃**，列表卡不读游记四态 |
| 根级 `handbookPhase` / `hasGuide`（若有） | 同样未进列表模型 |

### 3.2 `journey` 内未用于列表卡

| 字段 | 说明 |
|------|------|
| `clientId` | 映射保留，列表 UI 不用（写入/离线场景用） |
| `userId` | 未用 |
| `themeTags` / `themes` | 映射保留，**大卡不展示主题** |
| `budgetAmount` / `budgetLimit` | 映射保留，**大卡不展示预算** |
| `isPublic` | 未用 |
| `syncVersion` | 未用 |
| `days` / `nights` | 未用（天数由 start/end 现场算） |
| `updatedAt` | 映射保留，时间轴用的是 `createdAt` |
| `totalExpenseCent` / `expenseTotal` / `entryCount` 等平铺统计 | 列表优先用 `journeyStats`；journey 上平铺统计仅作 fallback |
| `plan`（若夹在 journey 里） | 列表不读 |

### 3.3 `journeyStats` 内未用

| 字段 | 说明 |
|------|------|
| `todayPlaceCount` | 已定义在 DTO，**前端未映射、未展示**（文案里「今日已到访」目前误用累计 `placeCount`，未接今日字段） |

### 3.4 `planProgress` 内未用

| 字段 | 说明 |
|------|------|
| `source` | 未读 |

## 4. 按 UI 区块对照（便于联调）

| UI 区块 | 依赖字段 |
|---------|----------|
| 时间轴标签 | `journey.createdAt` + 展示态（status/displayStatus + 日期） |
| 封面 | `journey.coverUrl` / `cover` |
| 标题 | `journey.title` |
| 状态徽章 | 展示态（同上） |
| Day / 倒计时 / % 徽章 | `startDate`/`endDate`；规划中另需 `planProgress.pct` |
| 主说明行 | `placeCount`；即将出发 + `planProgress`；已完成 + `recordCount`/`expenseTotal` |
| 副指标行 | 进行中：`placeCount` + `expenseTotal` + `companions`；即将出发：`startDate`；规划中：`placeCount` + `pct`；已完成：`placeCount` + `expenseTotal` + 目的地 |
| 进度条 | 进行中：起止日推算；规划中：`planProgress.pct` |
| 主/次按钮 | 仅依赖展示态（不读 handbook） |
| 长按菜单 | `id` + 展示态（是否显示「结束旅程」） |

## 5. 精简建议（给后端裁剪模块）

列表接口若只服务首页 / 我的旅程大卡，建议：

1. **可不返回** `handbook`（或 `modular` 时默认不带 handbook）。
2. **`journey` 建议保留最小集**：  
   `id`, `title`, `coverUrl`, `origin`, `destination`, `startDate`, `endDate`, `status`, `displayStatus`, `companions`, `createdAt`
3. **`journeyStats` 建议保留**：  
   `placeCount`, `recordCount`, `expenseTotalCent`  
   （若要修正「今日已到访」文案，再补 `todayPlaceCount` 并让前端接上）
4. **`planProgress` 建议保留**：  
   `checkDone`, `checkTotal`, `pct`  
   （即将出发 / 规划中依赖；纯进行中列表也可带，前端会忽略待办）

筛选参数（请求体，与本文响应字段无关）：`type` / `keyword` / `startTime` / `endTime` / `page` / `pageSize` / `modular`。
