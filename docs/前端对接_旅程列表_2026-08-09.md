# 前端对接 · 旅程列表 `POST /journeys/list`（2026-08-09）

> **Base**：`/dream/v1` · Header：`Authorization: Bearer <token>` · **勿传 userId**  
> 用途：首页进行中列表、我的旅程大卡  
> **破坏性变更**：① 全局前缀 `api`→`dream`；② `list[]` 由四模块嵌套改为**扁平单对象**（仅 list；`get` / `create` / `detail` 结构未改）  
> 前缀说明：`docs/前端对接_全局前缀_dream_2026-08-09.md`

---

## 1. 请求

```http
POST /dream/v1/journeys/list
Content-Type: application/json
```

```json
{
  "type": 1,
  "keyword": "杭州",
  "startTime": "2026-08-01",
  "endTime": "2026-08-31",
  "page": 1,
  "pageSize": 50
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | number | 否 | **不传=全部**；`1` 进行中；`2` 即将出发；`3` 规划中；`4` 已完成 |
| `keyword` | string | 否 | 模糊匹配**计划名称**（`title`） |
| `startTime` | string | 否 | 行程区间起，建议 `YYYY-MM-DD` |
| `endTime` | string | 否 | 行程区间止，建议 `YYYY-MM-DD` |
| `page` | number | 否 | 默认 `1` |
| `pageSize` | number | 否 | 默认 `20`，最大 `100` |
| `modular` | boolean | 否 | **已废弃**，可省略；列表固定扁平结构 |

### `type` → `displayStatus`

| type | Tab | 返回的 `displayStatus` |
|------|-----|------------------------|
| 不传 | 全部 | 混合 |
| `1` | 进行中 | `ongoing` |
| `2` | 即将出发 | `departing` |
| `3` | 规划中 | `planning` |
| `4` | 已完成 | `finished` |

时间区间：与旅程 `startDate`/`endDate` 做**交集**；两端都传且起 > 止 → `40001` 参数错误。

### 2.1 `list[]` 字段（根上直接读，无嵌套）

| 字段 | 类型 | 用途 |
|------|------|------|
| `id` | string | 跳转详情/计划/结束/删除 |
| `title` | string | 卡片标题 |
| `coverUrl` | string \| null | 封面 |
| `origin` | string \| null | 已完成短地名等 |
| `destination` | string \| null | 同上 |
| `startDate` | string | Day / 倒计时 /「MM.DD 出发」 |
| `endDate` | string | 行程总天数 |
| `status` | string | 持久化：`planned` \| `ongoing` \| `finished` |
| `displayStatus` | string | **展示态优先**：`planning` \| `departing` \| `ongoing` \| `finished` |
| `companions` | string[] | 进行中「N 人」 |
| `createdAt` | string | 时间轴「今天/昨天/M.D」 |
| `placeCount` | number | 「N 地点」 |
| `recordCount` | number | 已完成「N 条记录」 |
| `expenseTotalCent` | number | 花费，**单位：分** |
| `checkDone` | number | 即将出发：已完成检查项 |
| `checkTotal` | number | 即将出发：检查项总数（剩余 = total − done） |
| `pct` | number | 规划中：进度 0–100 |

分页：`total` / `page` / `pageSize`（先筛选再分页）。

### 2.2 列表不再返回

- `journey` / `journeyStats` / `planProgress` / `handbook` 整模块  
- `todayPlaceCount`、`clientId`、`themeTags`、`budgetAmount`、`days`、`nights` 等  

游记四态：`POST /journeys/handbook/list`（另接口）。

## 3. 前端改造清单

1. `mapJourneyListItem`：改为读**根字段**，不要再取 `item.journey`。
2. 建议映射：
   - `cover` ← `coverUrl`
   - `expenseTotal` ← `expenseTotalCent`（注意分→元）
   - `planProgress` ← `{ checkDone, checkTotal, pct }`
   - 徽章/按钮优先 `displayStatus`
3. 请求可去掉 `modular: true`。
4. `get` / `create` / `update` / `detail` **结构未变**，勿与 list 混用同一套嵌套解析（或做形态兼容）。

### 映射示例

```ts
type JourneyListCard = {
  id: string
  title: string
  coverUrl: string | null
  origin: string | null
  destination: string | null
  startDate: string
  endDate: string
  status: string
  displayStatus: 'planning' | 'departing' | 'ongoing' | 'finished'
  companions: string[]
  createdAt: string
  placeCount: number
  recordCount: number
  expenseTotalCent: number
  checkDone: number
  checkTotal: number
  pct: number
}

function mapJourneyListCard(row: JourneyListCard) {
  return {
    id: row.id,
    title: row.title,
    cover: row.coverUrl,
    origin: row.origin,
    destination: row.destination,
    startDate: row.startDate,
    endDate: row.endDate,
    status: row.status,
    displayStatus: row.displayStatus,
    companions: row.companions ?? [],
    createdAt: row.createdAt,
    placeCount: row.placeCount ?? 0,
    recordCount: row.recordCount ?? 0,
    expenseTotal: row.expenseTotalCent ?? 0,
    planProgress: {
      checkDone: row.checkDone ?? 0,
      checkTotal: row.checkTotal ?? 0,
      pct: row.pct ?? 0,
    },
  }
}
```
