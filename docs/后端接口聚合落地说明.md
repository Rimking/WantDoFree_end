# 后端接口聚合落地说明（对齐前端盘点）

> 日期：2026-07-24  
> 依据：`docs/渡清川_接口聚合与缓存策略盘点_2026-07-24.md`  
> 原则：**无参 GET；有参一律 POST + JSON body；聚合按模块嵌套；单查保留且与聚合同构**

---

## 1. 已落地（P0）

| 能力 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 旅程详情聚合 | POST | `/journeys/detail` | body:`{ journeyId, include? }` |
| 统计首页聚合 | POST | `/stats/dashboard` | body: range 筛选 |
| 旅程列表（模块化） | POST | `/journeys/list` | body:`{ status?, displayStatus?, page?, pageSize?, modular? }` |
| 旅程单查 | POST | `/journeys/get` | `{ id }` → `journey` + `journeyStats` + `planProgress` |
| 统计单资源 | POST | `/stats/overview|expenses|plans|journeys|content` | 与 dashboard 子模块同构 |
| 存储 | GET/POST | `/stats/storage` | 无参可 GET |

### 1.1 `POST /journeys/detail`

**Request**

```json
{
  "journeyId": "uuid",
  "include": ["entries", "plan", "expense", "guide"]
}
```

`include` 默认 `["entries","plan","expense"]`。

**Response（根上只有模块）**

```json
{
  "journey": { "id", "title", "coverUrl", "status", "displayStatus", "..." },
  "journeyStats": { "placeCount", "recordCount", "expenseTotalCent", "todayPlaceCount" },
  "planProgress": { "checkDone", "checkTotal", "pct" },
  "plan": { "places", "checks", "budgetEstimate" },
  "entries": [ /* Entry 模块 */ ],
  "expense": { "totalCent", "count", "byCategory", "byDay" },
  "guide": null
}
```

含 `guide` 时：无攻略返回 `{ exists:false, canGenerate, reason, stats }`，不抛 404。

### 1.2 `POST /stats/dashboard`

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "range": { "type", "start", "end" },
    "overview": {},
    "expenses": {},
    "plans": {},
    "journeys": {},
    "content": {},
    "storage": {}
  }
}
```

## 2. 单查 POST 别名（保留旧 GET/PATCH）

| 域 | 新 POST | Body | 旧兼容 |
|----|---------|------|--------|
| 旅程 | `/journeys/create|update|delete|status|finish` | 含 `id` 或创建字段 | `POST/GET/PATCH/DELETE /journeys/:id…` |
| 计划 | `/journeys/plan/get|save|toggleCheck` | `journeyId`… | `GET/PUT/PATCH /journeys/:id/plan` |
| 记录 | `/journeys/entries/list|sync|delete` | `journeyId`… | `GET/POST /journeys/:id/entries…` |
| 花费 | `/journeys/expense/summary` | `{ journeyId }` | `GET …/expense-summary` |
| 全局花费 | `/me/expense/summary` | `{ year? }` | `GET /me/expense-summary?year=` |
| 手帐 | `/journeys/guide/get|create|favorite` | `{ journeyId }` | `GET/POST /journeys/:id/guide…` |
| POI | `/pois/nearby|search|reverseGeocode` | lat/lng/keyword… | 旧 GET + query |
| 预算 | `/me/budget/get|update` | year / amount | GET/PATCH `/me/budget` |
| 资料 | `/me/update`、`/user/profile/update` | patch | PATCH |

统计旧 `GET /stats/*?rangeType=` 仍可用一期。

---

## 3. 模块化约定（前端解析）

1. 聚合 / 新 list / get：**读模块对象**，不要假设根上平铺 `title`/`totalCent`。  
2. Entry 正式字段：`location` / `expense` / `media` / `audio`；`legacy.images` 等仅兼容。  
3. 列表默认不返回完整 places/entries/guide。  
4. 别名收敛：新契约优先 `coverUrl`、`amountCent`、`nickname`（用户侧）。

---

## 4. 缓存（后端侧）

- 本轮 **未接 Redis**；聚合仅为减少 RTT，真源仍是服务端实时查。  
- 前端勿把 journeys/plans/stats 本地当真源（见盘点 §5）。

---

## 5. 前端改接线最小集

1. 详情页：一次 `POST /journeys/detail`（需要手帐时 `include` 含 `guide`）。  
2. 统计首页：一次 `POST /stats/dashboard`。  
3. 列表：`POST /journeys/list`，渲染 `item.journey` + `item.journeyStats`。  
4. 局部刷新继续用对应单查 POST。  
5. 旧 GET 可暂留回退，发版后切 POST。

---

## 6. 联调示例

```bash
TOKEN=...
# 详情
curl -s -X POST http://127.0.0.1:3000/api/v1/journeys/detail \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"journeyId":"bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbb0002","include":["entries","plan","expense","guide"]}'

# 统计看板
curl -s -X POST http://127.0.0.1:3000/api/v1/stats/dashboard \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"rangeType":"year","start":"2026"}'
```
