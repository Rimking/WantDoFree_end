## 3. 领域模型（本期落地）

### 3.1 会员（沿用 users 字段，不强制拆 UserMembership 表）

```
users.plan              free | pro
users.memberExpireAt
users.autoRenew
users.memberSinceAt
users.quotaPhoto / quotaVoiceSec / used*
member_plans            运营套餐
orders                  会员订单（planCode/periodDays/autoRenew/expireAt）
```

> PRD 的 `UserMembership` 与 `users` 一行等价；本期**不拆表**，避免迁移成本。历史订阅靠 `orders` 追溯。

### 3.2 邀请（新增）

```
invite_codes     userId UNIQUE, code UNIQUE
invite_records   inviterId + inviteeId UNIQUE
                 status: REGISTERED | ACTIVATED | REWARDED
                 rewardDays, rewardedAt
```

发奖：对被邀请人首开（mock pay / 未来微信回调）时，双方 `memberExpireAt` **顺延 30 天**；邀请人累计 ACTIVATED≥3 且未发过大奖时再顺延 **365 天**。

### 3.3 分享导出策略（无独立表，运行时算）

```
sharer.plan === 'pro' && 未过期 → watermark=false, maxResolution=1080
否则 → watermark=true, watermarkText='渡清川·免费版', maxResolution=720
```

## 4. 状态机（对外契约）

### 4.1 会员展示 status

| status | 含义 |
|--------|------|
| `FREE` | 未开通过或已降级 |
| `ACTIVE` | pro 且未过期 |
| `EXPIRED` | 曾为 pro 且已过期（惰性降级前一瞬可短暂返回；降级后多为 FREE，用 `wasMember`/`memberSinceAt` 辅助挽回） |
| `REFUNDED` | 最近一笔会员订单为 refunded 且当前 free（可选派生） |
| `PENDING` | 存在未过期 pending 订单（可选派生） |

本期 `GET /membership/me` 主字段：`status` ∈ FREE|ACTIVE|EXPIRED；附加 `pendingOrderNo?`、`lastRefundAt?`。

### 4.2 订单 status（现网）

`pending` → `paid` | `closed` | `refunded`；（P1）超时 → `expired`

## 6. 履约核心算法

### 6.1 顺延会员天数

```
base = max(now, user.memberExpireAt ?? now)
user.memberExpireAt = base + periodDays
user.plan = pro
quota → 300 / 10800
```

### 6.2 首月特惠

```
hasPaidMembership = exists order where userId & status=paid & planCode in membership
monthly 有效价 = !hasPaidMembership && firstMonthDiscountCent ? discount : priceCent
```

### 6.3 邀请发奖（开通时）

```
record = InviteRecord(invitee, status=REGISTERED)
on invitee first paid membership:
  extend(invitee, 30); extend(inviter, 30)
  record → REWARDED
  if inviter ACTIVATED/REWARDED count == 3 and !bonusGranted: extend(inviter, 365)
```
