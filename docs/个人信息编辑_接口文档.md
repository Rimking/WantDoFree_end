# 个人信息编辑 · 接口说明

> 对应需求：[渡清川_个人信息编辑页_需求文档.html](./渡清川_个人信息编辑页_需求文档.html)  
> Base：`/api/v1/user` · 鉴权：`Authorization: Bearer <token>`  
> 成功响应：**裸 JSON**（与途记现有约定一致，无 `{code:0,data}` 包装）  
> 错误响应：`{ code, message, timestamp, path }`（如 `40001`）

---

## 1. 获取资料

`GET /user/profile`

```json
{
  "userId": "aaaaaaaa-1111-1111-1111-111111111111",
  "nickname": "途记演示",
  "avatarUrl": "https://...",
  "gender": "FEMALE",
  "birthday": "1995-08-12",
  "provinceCode": "330000",
  "cityCode": "330100",
  "region": "浙江·杭州",
  "departureCity": "杭州萧山",
  "bio": "把每一次出发，都藏进清川。",
  "phoneMasked": "138****6621",
  "memberLevel": "FREE",
  "identities": ["backpacker", "foodie"],
  "stats": { "footprintCities": 12, "tripCount": 4 },
  "updatedAt": "..."
}
```

| 字段 | 说明 |
|------|------|
| `region` | 后端按省市编码拼接，前端勿本地拼 |
| `phoneMasked` | 仅脱敏；明文不返回 |
| `memberLevel` | `FREE` / `PRO`（来自套餐 plan） |
| `identities` | 旅行身份 code 数组，≤3 |

---

## 2. 保存资料

`PATCH /user/profile`（局部更新，仅传变更字段）

```json
{
  "nickname": "旅人",
  "avatarUrl": "https://cdn.../avatars/xxx.jpg",
  "gender": "FEMALE",
  "birthday": "1995-08-12",
  "provinceCode": "330000",
  "cityCode": "330100",
  "departureCity": "杭州萧山",
  "bio": "把每一次出发，都藏进清川。",
  "identities": ["backpacker", "foodie"]
}
```

成功：

```json
{
  "updatedAt": "...",
  "profile": { "...": "同 GET /profile 全量" }
}
```

清空可选字段可传 `null`（如 `birthday`、`bio`、`cityCode`）。

## 3. 头像预签名

`POST /user/avatar/presign`

```json
{ "ext": "jpg", "contentType": "image/jpeg" }
```

```json
{
  "secretId": "AKID_mock",
  "secretKey": "mock_secret",
  "sessionToken": "mock_session",
  "expiredTime": 1690000300,
  "bucket": "tuji-avatar-mock",
  "region": "ap-guangzhou",
  "key": "avatars/{userId}_{ts}.jpg",
  "cdnUrl": "https://cdn.example.com/avatars/...",
  "expiresIn": 300,
  "mock": true,
  "uploadUrl": "mock://...",
  "method": "PUT"
}
```

> COS 未配置时 `mock: true`：联调可直接把 `cdnUrl`（或本地上传后的 URL）写入 PATCH `avatarUrl`。  
> `ext`：`jpg|jpeg|png|webp`；单文件约束 ≤2MB 由前端拦截。

## 5. 省市区（联动）

`GET /user/regions`

```json
{
  "provinces": [
    {
      "code": "330000",
      "name": "浙江",
      "cities": [{ "code": "330100", "name": "杭州" }, ...]
    }
  ]
}
```

保存资料时 `cityCode` 必须在此白名单内，否则 `40006`。

---

## 6. 昵称实时校验（可选）

`POST /user/nickname/check`

```json
{ "nickname": "旅人" }
```

```json
{ "available": true }
```

或：

```json
{ "available": false, "code": "40002", "message": "昵称已被占用" }
```

---

## 7. 错误码

| code | 含义 |
|------|------|
| `40001` | 昵称/生日等格式不合法、敏感词 |
| `40002` | 昵称已被占用 |
| `40003` | 签名过长 |
| `40004` | 旅行身份 code 非法 |
| `40005` | 旅行身份超过 3 个 |
| `40006` | 所在地编码无效 |
| `401` | 未登录（HTTP） |

---

## 8. 校验摘要（前后端一致）

| 字段 | 规则 |
|------|------|
| nickname | 必填语义；2–12；trim；不能纯符号/emoji；敏感词 |
| gender | `MALE` / `FEMALE` / `UNKNOWN` |
| birthday | `YYYY-MM-DD`，1900～今天，可空 |
| cityCode | 6 位，须在 regions 白名单；选市级 |
| identities | ≤3，code 在字典内 |
| departureCity | ≤64 |
| bio | ≤40 |

---

## 9. 联调示例

```bash
TOKEN=$(curl -s http://localhost:3000/api/v1/auth/wechat-login \
  -H 'Content-Type: application/json' \
  -d '{"code":"dev_openid_demo"}' | jq -r .token)

curl -s http://localhost:3000/api/v1/user/profile \
  -H "Authorization: Bearer $TOKEN" | jq .

curl -s -X PATCH http://localhost:3000/api/v1/user/profile \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"bio":"把每一次出发，都藏进清川。","identities":["backpacker","foodie"]}' | jq .
```

种子用户已带：杭州所在地、FEMALE、生日、手机脱敏、背包客+美食猎人。

兼容：原 `GET/PATCH /me` 仍可用（昵称/头像）；编辑页请统一走 `/user/profile`。
