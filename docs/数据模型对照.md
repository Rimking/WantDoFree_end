# 途记 · 数据模型对照

> 库名：`tuji`（MySQL 8，utf8mb4）  
> ORM：TypeORM Entity ↔ 表名一对一；主键均为 UUID（varchar(36)）  
> Entity 路径：`src/entities/`  
> 初始迁移：`src/migrations/1784641830216-Init.ts`  
> 前端对齐：`1784800000000-FrontendAlign.ts`（origin / plan / year_budgets / status）

## 1. 表总览

| 表名 | Entity | 模块 | 用途 |
|------|--------|------|------|
| `users` | `User` | auth / user / quota / payment | 用户、套餐、配额 |
| `journeys` | `Journey` | journey | 旅程（R1） |
| `journey_plans` | `JourneyPlan` | journey | 旅行计划 |
| `entries` | `Entry` | recording | 时间线条目（聚合体） |
| `locations` | `Location` | recording / location | 位置点 |
| `expenses` | `Expense` | recording / expense | 花费（分类英文 key） |
| `media` | `Media` | recording / media | 照片/语音（多条） |
| `guides` | `Guide` | guide | 攻略（R5） |
| `share_events` | `ShareEvent` | guide | 分享归因 |
| `year_budgets` | `YearBudget` | user | 年度预算 |
| `orders` | `Order` | payment | 订单 |
| `drafts` | `Draft` | draft | 草稿箱 |

## 2. ER 关系

```
users 1───N journeys 1───1 journey_plans
                │
                └───N entries 1───1 locations
                              │   1───1 expenses
                              │   1───N media
                └───1 guides 1───N share_events
users 1───N orders
users 1───N year_budgets
```

外键多为 `ON DELETE CASCADE`。

## 3. 字段对照（核心变更）

### journeys

| 列 | 说明 |
|----|------|
| origin | 出发地，创建必填 |
| destination | 目的地，**可空** |
| status | `planned` \| `ongoing` \| `finished`（写入兼容 planning/ended） |
| themeTags / companions | JSON，**英文 key** |
| clientId | 离线幂等（userId+clientId 唯一） |
| budgetAmount | 预算（分）；API 兼容 budgetLimit |

### journey_plans

| 列 | 说明 |
|----|------|
| places | `{ clientId, name, note?, coverUrl? }[]` |
| checks | `{ clientId, text, done }[]` |
| budgetEstimate | 预估预算（分） |

### entries

聚合体：一条可同时有 content / media[] / location / expense；`type` 含 `expense`。

### year_budgets

`userId + year` 唯一；`amountCent`。
