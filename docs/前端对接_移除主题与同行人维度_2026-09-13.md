# 前端对接：移除「主题」与「同行人」维度（2026-09-13）

> 变更背景：产品决定下线「主题（themeTags）」与「同行人（companions）」两个维度。
> 后端已完成：接口入参/出参、实体列、字典枚举、内存映射、历史 JSON 残留全链路清理。
> 本文档供前端对照删除对应内容；mini 小程序触点清单见 §5。

---

## 1. 变更概述

| 层 | 变更内容 |
|---|---|
| 接口入参 | `POST /journeys/create`、`POST /journeys/update` 不再接受 `themeTags` / `themes` / `companions` |
| 接口出参 | 所有涉及接口的响应中不再出现 `themeTags` / `themes` / `companions` / `themeLabel` |
| 数据库 | `journeys` 表删除 `themeTags`、`companions` 两列；`guides.payload.meta.themeTags`、`drafts.payload.themeTags` 历史残留已清洗 |
| 字典枚举 | `THEME_TAGS / THEME_LABELS / COMPANIONS / normalizeThemeTag / normalizeCompanion / themeLabelOf` 已删除 |
| 迁移 | `src/migrations/1789310400000-RemoveJourneyThemeCompanions.ts`（生产库启动自动执行；dev 库已手动执行） |

---

## 2. 接口入参变更（create / update）

| 字段 | 状态 | 说明 |
|---|---|---|
| `themeTags` | ❌ 已删除 | 传入会被忽略 |
| `themes` | ❌ 已删除 | 同上 |
| `companions` | ❌ 已删除 | 同上（`solo` 与其他互斥校验一并移除） |

**兼容性**：全局 `ValidationPipe({ whitelist: true })` 会**静默剥离**未声明字段——老版本小程序继续传这三个字段**不会报错（不会 400）**，但值不会落库。

> 建议前端尽快删除入参字段，避免「传了但没生效」的隐性不一致。

## 7. 注意事项

1. **老前端 × 新后端共存**：传旧字段不报错但被剥离；展示层读 `themeLabel` / `companions` 会得到 `undefined`——需按 §5 删除展示逻辑，避免出现空白标签/空文案。
2. **本地缓存清理**：jotai storage / 本地持久化中旧的 journey 缓存对象可能仍带 `companions` / `themes`，展示前建议以接口最新数据覆盖；对缓存字段做读取兜底。
3. **`plan` 结构同步**：`/journeys/detail` 的 `plan` 内嵌对象也不再含这三个字段，编辑预定点场景不受影响。
4. 相关文档已同步更新：《后端接口一览》《itemDetail 拆分》《handbookDetail 拆分》《旅行徽章体系 PRD》。
