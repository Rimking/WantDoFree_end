# 前端对接 · 旅程列表卡片扁平化（2026-08-09）

> **接口**：`POST /api/v1/journeys/list` · JWT  
> **变更性质**：列表响应结构 **破坏性变更**（模块嵌套 → 单对象扁平）  
> 详情 / 创建 / 更新 / get 仍为模块化结构，**仅 list 变更**。

---

## 1. 为什么改

旧结构每条为四个模块（`journey` / `journeyStats` / `planProgress` / `handbook`），体积大且列表卡用不到大半字段（尤其 `handbook`）。  
现按《旅程列表卡片字段使用说明》只返回卡片实际消费字段，聚合为 **一个对象**。

## 3. 字段表（`list[]` 每一项）

| 字段 | 类型 | 原路径 | 用途 |
|------|------|--------|------|
| `id` | string | `journey.id` | 跳转 / 删除 / 结束 |
| `title` | string | `journey.title` | 标题 |
| `coverUrl` | string \| null | `journey.coverUrl` | 封面 |
| `origin` | string \| null | `journey.origin` | 短地名等 |
| `destination` | string \| null | `journey.destination` | 短地名等 |
| `startDate` | string | `journey.startDate` | 展示态 / Day / 倒计时 |
| `endDate` | string | `journey.endDate` | 同上 |
| `status` | string | `journey.status` | 持久化态 planned/ongoing/finished |
| `displayStatus` | string | `journey.displayStatus` | 展示态 planning/departing/ongoing/finished（**优先用这个**） |
| `companions` | string[] | `journey.companions` | 「N 人」 |
| `createdAt` | string | `journey.createdAt` | 时间轴 |
| `placeCount` | number | `journeyStats.placeCount` | 地点数文案 |
| `recordCount` | number | `journeyStats.recordCount` | 已完成「N 条记录」 |
| `expenseTotalCent` | number | `journeyStats.expenseTotalCent` | 花费（分） |
| `checkDone` | number | `planProgress.checkDone` | 即将出发待办 |
| `checkTotal` | number | `planProgress.checkTotal` | 同上 |
| `pct` | number | `planProgress.pct` | 规划中进度 % |

### 3.1 明确不再返回（列表）

- 整模块：`journey` / `journeyStats` / `planProgress` / `handbook`
- `todayPlaceCount`、`source`、`clientId`、`themeTags`、`budgetAmount`、`days`/`nights`、`syncVersion`、`isPublic`、`updatedAt` 等

游记四态请继续用：`POST /journeys/handbook/list`。

### 3.2 请求体说明

| 字段 | 说明 |
|------|------|
| `type` / `keyword` / `startTime` / `endTime` / `page` / `pageSize` | 筛选分页不变 |
| `modular` | **已废弃**，传了也不影响；列表固定扁平卡片 |

## 4. 前端改造要点

1. **去掉** `mapJourneyListItem` 对嵌套模块的假设；改为直接读根字段，或写 `mapJourneyListCard(item)`。
2. 领域模型建议映射：
   - `cover` ← `coverUrl`
   - `expenseTotal` ← `expenseTotalCent`
   - `planProgress` ← `{ checkDone, checkTotal, pct }`
   - 展示态优先 `displayStatus`
3. `create` / `update` / `get` / `detail` **未改**，仍可用原 `mapJourneyListItem` / 模块结构。
4. 若本地曾用 `modular: true`，可删，无功能影响。

### 4.1 映射伪代码

```ts
function mapJourneyListCard(row: ListCard): Journey {
  return {
    id: row.id,
    title: row.title,
    cover: row.coverUrl,
    origin: row.origin,
    destination: row.destination,
    startDate: row.startDate,
    endDate: row.endDate,
    status: row.status,
    displayStatus: row.displayStatus,
    companions: row.companions ?? [],
    createdAt: row.createdAt,
    placeCount: row.placeCount,
    recordCount: row.recordCount,
    expenseTotal: row.expenseTotalCent,
    planProgress: {
      checkDone: row.checkDone,
      checkTotal: row.checkTotal,
      pct: row.pct,
    },
  }
}
```

## 5. 联调验收
