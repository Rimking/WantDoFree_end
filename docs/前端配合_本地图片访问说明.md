# 前端本地图片访问说明

> 日期：2026-07-26  
> Base：`/api/v1`  
> 存储：本地 `uploadImgFile/`（`STORAGE_DRIVER=local`，无 CDN）  
> 鉴权：除登录外统一 `Authorization: Bearer <token>`

---

## 1. 结论（先看这个）

| 问题 | 答案 |
|------|------|
| 接口返回的图片地址长什么样？ | 相对路径：`/api/v1/files/yyyy/mm/dd/{uuid}.ext` |
| 能不能直接塞给 `<image :src>`？ | **不能**（会 401） |
| 正确做法 | 用 **`AuthImage`**，或先 **`resolveMediaUrl`** 再展示 |
| 文件落盘在哪？ | 服务端 `uploadImgFile/yyyy/mm/dd/...`（前端不直接读磁盘） |

## 2. URL 形态

### 2.1 本地上传成功后（库内 / 接口字段）

```text
/api/v1/files/2026/07/25/c5b06485-9c7f-4177-a697-51581a208aa1.jpg
```

常见字段：`avatar` / `avatarUrl` / `coverUrl` / `media[].url` / `images[]` 等。

### 2.2 拼绝对地址（请求用）

```text
{APP_ORIGIN}/api/v1/files/2026/07/25/xxx.jpg
```

示例（本地）：

```text
http://127.0.0.1:3000/api/v1/files/2026/07/25/xxx.jpg
```

真机联调把 host 换成电脑局域网 IP。

### 2.3 两类 URL

| 类型 | 例子 | 展示方式 |
|------|------|----------|
| 本地媒体（需鉴权） | `/api/v1/files/...` | `AuthImage` / `resolveMediaUrl` |
| 外链（种子图等） | `https://images.unsplash.com/...` | 可直接作 `src` |
| 选图临时路径 | `wxfile://` / `http://tmp/...` | 上传前本地预览用；上传后改用接口 url |

---

## 3. 为什么不能裸链

`GET /api/v1/files/:y/:m/:d/:file`：

1. 必须登录（JWT）  
2. 校验文件归属（只能读自己的）  
3. 无 Token → **401**；非本人 → **403**

小程序 `<image>` **不会**自动带 `Authorization`，所以相对路径 / 绝对 files URL 直接当 `src` 会失败，看起来像「头像没更新」。

## 4. 推荐用法（小程序）

### 4.1 组件（优先）

项目已有：`mini/src/components/media/AuthImage.vue`（内部走 `SafeImage` → `resolveMediaUrl`）。

```vue
<template>
  <!-- 头像 / 封面 / 任意本地媒体 -->
  <view class="h-24 w-24 overflow-hidden rounded-full">
    <AuthImage
      v-if="avatarUrl"
      :src="avatarUrl"
      mode="aspectFill"
      fallback-color="#2BB3A3"
    />
    <text v-else>{{ nickname[0] }}</text>
  </view>
</template>

<script setup lang="ts">
import AuthImage from '@/components/media/AuthImage.vue'
</script>
```

### 4.2 工具函数

文件：`mini/src/lib/mediaUrl.ts`

```ts
import { resolveMediaUrl, resolveMediaUrls } from '@/lib/mediaUrl'

// 单张
const src = await resolveMediaUrl('/api/v1/files/2026/07/25/xxx.jpg')
// src → 本机临时路径，可安全给 <image :src="src">

// 多张
const list = await resolveMediaUrls(urls)
```

内部步骤：

1. 识别是否为 `/api/v1/files/...`  
2. 拼绝对 URL  
3. `uni.downloadFile`，Header 带 `Authorization: Bearer <token>`  
4. 用 `tempFilePath` 展示（带简单缓存）

### 4.3 错误示例

```vue
<!-- ❌ 401，图不出来 -->
<image :src="user.profile.avatar" />

<!-- ❌ 缺 Token -->
<image :src="'http://127.0.0.1:3000' + avatarUrl" />
```

## 5. 上传与展示闭环

```
选图 (wxfile)
  → POST /media/prepare
  → POST /media/local-upload（multipart file）
  → POST /media/confirm
  → 接口返回 url = /api/v1/files/...
  → 写入 users.avatar / 业务字段
  → 展示时用 AuthImage(url)
```

头像细节另见：[前端配合_头像上传对接说明.md](./前端配合_头像上传对接说明.md)

## 6. H5 / 调试用 curl

```bash
TOKEN=...
curl -H "Authorization: Bearer $TOKEN" \
  -o /tmp/a.jpg \
  "http://127.0.0.1:3000/api/v1/files/2026/07/25/xxx.jpg"
```

浏览器地址栏直接打开 files URL **通常不行**（没带 Header）。
