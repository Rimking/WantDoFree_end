# 前端对接 · 地图计划地点聚合

> 日期：2026-07-30  
> 用途：地图页按计划连点；一次拉取用户多个旅程的选点列表

---

## 接口

`POST /api/v1/journeys/destinations/mapList`  
鉴权：`Authorization: Bearer <token>`  
**userId 由 JWT 解析，不要传。**

### 入参

```json
{
  "startDate": "2026-01-01",
  "endDate": "2026-12-31",
  "journeyId": "可选，只查某一个旅程",
  "planId": "可选，journeyId 别名",
  "onlyWithCoords": true
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `startDate` / `endDate` | 否 | `YYYY-MM-DD`，须成对；过滤与区间**有交集**的旅程（`journey.start ≤ endDate` 且 `journey.end ≥ startDate`） |
| `journeyId` / `planId` | 否 | 只返回该计划；二者等价，优先 `journeyId` |
| `onlyWithCoords` | 否 | 默认 `true`：只返回有经纬度的点（便于折线）；`false` 含无坐标选点 |

都不传时间 → 当前用户全部旅程。

### 响应

```json
{
  "range": { "startDate": "2026-01-01", "endDate": "2026-12-31" },
  "onlyWithCoords": true,
  "totalPlaces": 5,
  "plans": [
    {
      "journeyId": "...",
      "planId": "...",
      "title": "杭嘉湖三日",
      "origin": "杭州",
      "destination": "嘉兴",
      "startDate": "2026-07-01",
      "endDate": "2026-07-03",
      "status": "planned",
      "coverUrl": null,
      "placeCount": 3,
      "places": [
        {
          "id": "...",
          "name": "西湖",
          "latitude": 30.242,
          "longitude": 120.148,
          "lat": 30.242,
          "lng": 120.148,
          "address": "杭州市西湖区…",
          "category": "SIGHT",
          "dayIndex": 1,
          "sortOrder": 0,
          "isMust": true,
          "source": "destination"
        }
      ]
    }
  ]
}
```

### 数据规则

1. **按旅程分组**，组内按 `sortOrder`（计划 JSON 回退时按数组顺序）  
2. 旅程排序：`startDate ASC` → `createdAt ASC`  
3. 选点来源：优先 `destinations` 表；该旅程无目的地时回退 `journey_plans.places`（`source`: `destination` | `plan`）  
4. 坐标字段双写：`latitude/longitude` 与 `lat/lng`
